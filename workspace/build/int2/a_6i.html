Tutor demo.

a

\[\begin{aligned}\int_e^{e^3}\dfrac4x\,dx&=4\Big[\log_e|x|\Big]_e^{e^3}\\&=4\big(\log_ee^3-\log_ee\big)\\&=4(3-1)\\&=8\end{aligned}\]

b \((a=-3\text{ and }b=1)\)

\[\begin{aligned}\int_1^3\dfrac{1}{1-3x}\,dx&=-\tfrac13\Big[\log_e|1-3x|\Big]_1^3\\&=-\tfrac13\big(\log_e|-8|-\log_e|-2|\big)\\&=-\tfrac13\big(\log_e8-\log_e2\big)\\&=-\tfrac13\log_e4\end{aligned}\]

In b, \(1-3\times3=-8\) and \(1-3\times1=-2\), and \(\log_e8-\log_e2=\log_e\tfrac82=\log_e4\).

c The denominator \(x-3\) is zero at \(x=3\), which lies between \(1\) and \(4\). This definite integral is meaningless because it crosses the asymptote at \(x=3\).

d The interval \(-4\le x\le-1\) is on the left-hand branch, so it does not cross \(x=0\).

\[\begin{aligned}\int_{-4}^{-1}\dfrac1x\,dx&=\Big[\log_e|x|\Big]_{-4}^{-1}\\&=\log_e|-1|-\log_e|-4|\\&=0-\log_e4\\&=-\log_e4\end{aligned}\]

The integral is negative because the region is below the \(x\)-axis (the diagram in Concept 2).

Tutor demo.

a Let \(u=x^2+5\). Then \(u'=2x\), so the top is the derivative of the bottom.

\[\begin{aligned}\int_0^2\dfrac{2x}{x^2+5}\,dx&=\Big[\log_e(x^2+5)\Big]_0^2\\&=\log_e9-\log_e5\end{aligned}\]

PP 1North Sydney Boys High School, 2022, HSC Course Assessment Task 3-Trial Examination, Mathematics Extension 1, Q13(a)(i)

The integrand needs \(\ln x\), so \(x\gt0\) (and \(x\ne1\), so that \(\ln x\ne0\)). Split the fraction into two separate fractions:

\[\begin{aligned}\dfrac{1-\ln x}{x\ln x}&=\dfrac{1}{x\ln x}-\dfrac{\ln x}{x\ln x}\\&=\dfrac{1}{x\ln x}-\dfrac1x.\end{aligned}\]

For the first fraction, let \(u=\ln x\). Then \(u'=\dfrac1x\), so

\[\dfrac{1}{x\ln x}=\dfrac{\tfrac1x}{\ln x}=\dfrac{u'}{u},\quad\text{and}\quad\int\dfrac{u'}{u}\,dx=\ln|u|=\ln|\ln x|.\]

Hence

\[\begin{aligned}\int\dfrac{1-\ln x}{x\ln x}\,dx&=\int\Big(\dfrac{1}{x\ln x}-\dfrac1x\Big)\,dx\\&=\ln|\ln x|-\ln x+C,\end{aligned}\]

for some constant \(C\). Here \(\ln|x|=\ln x\) because \(x\gt0\). Using a log law, this can also be written as \(\ln\Big|\dfrac{\ln x}{x}\Big|+C\).
