Lesson 6K

Calculus with other bases

The change-of-base formula writes every logarithmic function as a constant multiple of \(\log_ex\), and every exponential function \(a^x\) as a power of \(e\). With these we differentiate \(\log_ax\), show that base \(e\) is the only base whose logarithm has gradient 1 at its \(x\)-intercept, and differentiate and integrate \(a^x\). This gives three new standard forms: the derivatives of \(\log_ax\) and \(a^x\), and the primitive of \(a^x\).
{{sec:teal:key:Concept 1:logarithmic functions to other bases}}
Calculus with other bases

In applications of exponential functions where calculus is required, the base \(e\) can generally be used. For example, the treatment of exponential growth in Chapter 11 of the Year 11 book was done entirely using base \(e\).

The change-of-base formula, however, allows calculus to be applied to exponential and logarithmic functions of any base without conversion to base \(e\). In this section, we develop three further standard forms that allow calculus to be applied straightforwardly to functions such as \(y=2^x\) and \(y=10^x\).

Throughout this section, the other base \(a\) must be positive and not equal to 1.

Logarithmic functions to other bases

Any logarithmic function can be expressed easily in terms of \(\log_ex\) by using the change-of-base formula. For example,

\[\log_2x=\dfrac{\log_ex}{\log_e2}.\]

Thus every other logarithmic function is just a constant multiple of \(\log_ex\). This allows any other logarithmic function to be differentiated easily.

Where the change-of-base formula comes from
Let\(y=\log_ax.\)
Then\(a^y=x,\)by the definition of logarithms.
Take \(\log_e\) of both sides:\(\log_e\big(a^y\big)=\log_ex\)
\(y\log_ea=\log_ex,\)by the log law \(\log_e\big(a^n\big)=n\log_ea\).
Divide by \(\log_ea\):\(y=\dfrac{\log_ex}{\log_ea}.\)(\(\log_ea\ne0\), because \(a\ne1\).)
11 Logarithmic functions with other bases

Every logarithmic function can be written as a multiple of a logarithmic function base \(e\):

\[\log_ax=\dfrac{\log_ex}{\log_ea},\qquad\text{that is}\qquad\log_ax=\dfrac{1}{\log_ea}\times\log_ex.\]

{{sec:teal:key:Concept 2:differentiating logarithmic functions with other bases}}
Differentiating logarithmic functions with other bases

Once the function is expressed as a multiple of a logarithmic function base \(e\), it can be differentiated using the previous standard forms.

Part b of Worked example 40 below gives the formula in the general case:

12 Differentiating logarithmic functions with other bases
  • Either use the change-of-base formula to convert to logarithms base \(e\).
  • Or use the standard form \(\dfrac{d}{dx}\log_ax=\dfrac{1}{x\log_ea}\).
The constant factor stays

After the change of base, \(\log_ax=\dfrac{1}{\log_ea}\times\log_ex\). The factor \(\dfrac{1}{\log_ea}\) is a constant, and the derivative of a constant times a function is the constant times the derivative of the function. Since \(\dfrac{d}{dx}\log_ex=\dfrac1x\), the derivative is \(\dfrac{1}{\log_ea}\times\dfrac1x\).

{{sec:teal:key:Concept 3:a characterisation of the logarithmic function}}
A characterisation of the logarithmic function

We have already discussed in Section 6A that the tangent to \(y=\log_ex\) at the \(x\)-intercept has gradient exactly 1.

The worked example below shows that this property distinguishes the logarithmic function base \(e\) from all other logarithmic functions.

13 The gradient at the \(x\)-intercept

The function \(y=\log_ex\) is the only logarithmic function whose gradient at the \(x\)-intercept is exactly 1.

Two facts from the definition of logarithms

\(\log_ax=c\) means \(x=a^c\). So \(\log_ax=0\) gives \(x=a^0=1\). Thus every logarithmic function \(y=\log_ax\) has \(x\)-intercept \((1,0)\). In the same way, \(\log_ea=1\) gives \(a=e^1=e\).

Exponential functions with other bases

Before calculus can be applied to an exponential function \(y=a^x\) with base \(a\) different from \(e\), it must be written as an exponential function with base \(e\). The important identity used to do this is

\[e^{\log_ea}=a,\]

which simply expresses the fact that the functions \(e^x\) and \(\log_ex\) are inverse functions. Now \(a^x\) can be written as

\(a^x=\big(e^{\log_ea}\big)^x,\)replacing \(a\) by \(e^{\log_ea}\),
\(\phantom{a^x}=e^{x\log_ea},\)using the index law \(\big(e^k\big)^x=e^{kx}\).

Thus \(a^x\) has been expressed in the form \(e^{kx}\), where \(k=\log_ea\) is a constant.

Why \(e^{\log_ea}=a\)

By the definition of logarithms, \(\log_ea\) is the index to which \(e\) must be raised to give \(a\). So raising \(e\) to that index gives \(a\) back. For example, \(\log_e2\doteq0.6931\), and \(e^{0.6931}\doteq2\). In the second line above, the index law is used with \(k=\log_ea\), so \(kx=x\log_ea\).

14 Exponential functions with other bases
  • Every positive real number can be written as a power of \(e\): \[a=e^{\log_ea}\]
  • Every exponential function can be written as an exponential function base \(e\): \[a^x=e^{x\log_ea}\]

{{sec:teal:key:Concept 5:differentiating and integrating exponential functions with other bases}}
Differentiating and integrating exponential functions with other bases

Write the function as a power of \(e\). It can then be differentiated and integrated.

First,\(a^x=e^{\log_e a^x}\)
\(\phantom{a^x}=e^{x\log_ea}.\)
Differentiating,\(\dfrac{d}{dx}\,a^x=\dfrac{d}{dx}\,e^{x\log_ea}\)
\(\phantom{\dfrac{d}{dx}\,a^x}=e^{x\log_ea}\times\log_ea,\)because \(\dfrac{d}{dx}\,e^{kx}=ke^{kx}\),
\(\phantom{\dfrac{d}{dx}\,a^x}=a^x\log_ea,\)because \(e^{x\log_ea}=a^x\).
Integrating exponential functions with other bases
Integrating,\(\displaystyle\int a^x\,dx=\int e^{x\log_ea}\,dx\)
\(\displaystyle\phantom{\int a^x\,dx}=\dfrac{e^{x\log_ea}}{\log_ea},\)because \(\displaystyle\int e^{kx}\,dx=\dfrac1k\,e^{kx}\),
\(\displaystyle\phantom{\int a^x\,dx}=\dfrac{a^x}{\log_ea},\)because \(e^{x\log_ea}=a^x\).

This process can be carried through every time, or the results can be remembered as standard forms.

15 Differentiation and integration with other bases

There are two approaches.

  • Write all powers with base \(e\) before differentiating or integrating.
  • Alternatively, use the standard forms:
\[\dfrac{d}{dx}\,a^x=a^x\log_ea\qquad\text{and}\qquad\int a^x\,dx=\dfrac{a^x}{\log_ea}+C\]
Base \(e\) is the simplest

Note: The formulae for differentiating and integrating \(a^x\) both involve the constant \(\log_ea\). This constant \(\log_ea\) is 1 when \(a=e\), so the formulae are simplest when the base is \(e\). Again, this indicates that \(e\) is the appropriate base to use for calculus with exponential functions.

The derivation in detail
  • The first line uses the identity \(e^{\log_eb}=b\) with \(b=a^x\). Then the log law \(\log_e\big(a^x\big)=x\log_ea\) gives the second line.
  • The standard forms for \(e^{kx}\) are used with the constant \(k=\log_ea\).
  • The integration lines leave out the constant of integration. Box 15 adds it: \(\displaystyle\int a^x\,dx=\dfrac{a^x}{\log_ea}+C\).

Why \(x=0\)

The \(y\)-intercept is where \(x=0\). Since \(2^0=1\), the \(y\)-intercept of \(y=2^x\) is \((0,1)\), and the gradient there is \(1\times\log_e2=\log_e2\).

c

\[\begin{aligned}\text{Area}&=\int_0^1(\text{upper curve}-\text{lower curve})\,dx\\&=\int_0^1\big(x+1-2^x\big)\,dx\\&=\Big[\tfrac12x^2+x-\dfrac{2^x}{\log_e2}\Big]_0^1\\&=\Big(\tfrac12+1-\dfrac{2}{\log_e2}\Big)-\Big(0+0-\dfrac{1}{\log_e2}\Big)\\&=1\tfrac12-\dfrac{1}{\log_e2}\text{ square units}\\&\doteq0.05730\text{ square units.}\end{aligned}\]

The lines that Worked example 45 leaves out

a When \(x=0\): \(\ x+1=1\) and \(2^0=1\), so both pass through \(A(0,1)\). When \(x=1\): \(\ x+1=2\) and \(2^1=2\), so both pass through \(B(1,2)\).
