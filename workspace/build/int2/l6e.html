Lesson 6E

Applications of integration

The normal methods of finding areas by integration can now be applied to functions involving \(e^x\). We find the area between a curve and the \(x\)-axis, where a sketch is essential because regions below the axis give negative integrals, and the area between two curves, using the top curve minus the bottom curve.
{{sec:teal:key:Concept 1:the area between a curve and the x-axis}}
Finding the area between a curve and the \(x\)-axis

A sketch is essential here, because the definite integral attaches a negative sign to the area of any region below the \(x\)-axis (provided that the integral does not run backwards, that is, provided the lower limit is less than the upper limit).

  • Sketch the curve, showing the intercepts (and any asymptote).
  • Write down and evaluate the definite integral between the required \(x\)-values.
  • If the region is below the \(x\)-axis, the integral is negative, and the area is its opposite. If the region crosses the \(x\)-axis, split the integral at the \(x\)-intercept and find each part separately.
  • Write a conclusion, giving the area in square units.
Sketching by shifting

The graph of \(y=e^x-k\), where \(k\gt0\), is the graph of \(y=e^x\) moved down \(k\) units. Its \(y\)-intercept moves down from \(1\) to \(1-k\), and its horizontal asymptote moves down from \(y=0\) to \(y=-k\). Find the \(x\)-intercept by putting \(y=0\). For example, \(e^x=e^2\) gives \(x=2\), because \(e^x\) is an increasing function, so it takes the value \(e^2\) only once.

Worked example 17Keep for homework
a Use shifting to sketch \(y=e^x-e\), showing the intercepts and asymptote.
b Find the area of the region between this curve, the \(x\)-axis and the \(y\)-axis.
Solution

a Move the graph of \(y=e^x\) down \(e\) units.

When \(x=0\),\(y=e^0-e\)
\(\phantom{y}=1-e.\)
When \(y=0\),\(e^x=e\)
\(\phantom{e^x}x=1.\)

The horizontal asymptote moves down to \(y=-e\).

{{svg:c6e_ex17}}

b

\[\begin{aligned}\int_0^1(e^x-e)\,dx&=\Big[e^x-ex\Big]_0^1\qquad\text{(the number }e\text{ is a constant)}\\&=(e^1-e)-(e^0-0)\\&=-1.\end{aligned}\]

This integral is negative because the region is below the \(x\)-axis.
Hence the required area is \(1\) square unit.

Note: The primitive of the constant \(e\) is \(ex\), just as the primitive of \(3\) is \(3x\). In the second line, \(e^1-e=0\) and \(e^0-0=1\), so the value is \(0-1=-1\).

{{sec:teal:key:Concept 2:areas between curves}}
Finding areas between curves

If a curve \(y=f(x)\) is always above \(y=g(x)\) in an interval \(a\le x\le b\), then the area of the region between the curves is

\[\text{area between the curves}=\int_a^b\big(f(x)-g(x)\big)\,dx.\]

This is the top curve minus the bottom curve. The formula still works when part of the region lies below the \(x\)-axis, because only the difference \(f(x)-g(x)\) matters, and it is positive throughout the interval.

Worked example 18Keep for homework
a Sketch the curves \(y=e^x\) and \(y=x^2\) in the interval \(-2\le x\le2\).
b Find the area of the region between the curves, from \(x=0\) to \(x=2\).
Solution

a The graphs are drawn to the right.
Note that for \(x\gt0\), \(y=e^x\) is always above \(y=x^2\).

b Using the standard formula above,

\[\begin{aligned}\text{area}&=\int_0^2\big(e^x-x^2\big)\,dx\\&=\Big[e^x-\tfrac13x^3\Big]_0^2\\&=\big(e^2-\tfrac83\big)-\big(e^0-0\big)\\&=e^2-3\tfrac23\text{ square units.}\end{aligned}\]
{{svg:c6e_ex18}}

Note: The first line writes the formula with \(f(x)=e^x\) on top and \(g(x)=x^2\) below. In the third line, \(\tfrac13\times2^3=\tfrac83\) and \(e^0=1\), so the value is \(e^2-\tfrac83-1=e^2-3\tfrac23\).

Integrating with respect to \(y\) (from Section 5F)

A region bounded by a logarithmic curve is often easier to find by integrating with respect to \(y\). Write \(x\) as a function of \(y\), then integrate between \(y\)-values, using the right-hand curve minus the left-hand curve.

For example, the region between \(y=\log_ex\), the \(y\)-axis and the lines \(y=0\) and \(y=1\) is shown. Since \(y=\log_ex\), we have \(x=e^y\) by the definition of logarithms. So

{{svg:c6e_tipy}}
\[\begin{aligned}\text{area}&=\int_0^1e^y\,dy\\&=\Big[e^y\Big]_0^1\\&=e^1-e^0\\&=e-1\text{ square units.}\end{aligned}\]
