a When \(y=0\), \(\ \log_3x=0\), so \(x=3^0=1\). The \(x\)-intercept is \((1,0)\).

Differentiating,\(y'=\dfrac{1}{x\log_e3},\)
so when \(x=1\),\(y'=\dfrac{1}{1\times\log_e3}=\dfrac{1}{\log_e3},\ \) as required.

b The tangent passes through \((1,0)\) with gradient \(\dfrac{1}{\log_e3}\), so

\[\begin{aligned}y-0&=\dfrac{1}{\log_e3}\,(x-1)\\y&=\dfrac{x-1}{\log_e3}.\end{aligned}\]

c By part a with base \(a\), the gradient at the \(x\)-intercept is \(\dfrac{1}{\log_ea}\). So

\[\begin{aligned}\dfrac{1}{\log_ea}&=2\\\log_ea&=\tfrac12\\a&=e^{\frac12}=\sqrt e.\end{aligned}\]

Tutor demo.

a When \(x=0\): \(\ 2x+1=1\) and \(3^0=1\). When \(x=1\): \(\ 2x+1=3\) and \(3^1=3\). So both graphs pass through \(A(0,1)\) and \(B(1,3)\).

c At \(x=\tfrac12\), \(\ 2x+1=2\) and \(3^{\frac12}=\sqrt3\doteq1.732\), so the line is the upper curve.

\[\begin{aligned}\text{Area}&=\int_0^1\big(2x+1-3^x\big)\,dx\\&=\Big[x^2+x-\dfrac{3^x}{\log_e3}\Big]_0^1\\&=\Big(1+1-\dfrac{3}{\log_e3}\Big)-\Big(0+0-\dfrac{1}{\log_e3}\Big)\\&=2-\dfrac{3}{\log_e3}+\dfrac{1}{\log_e3}\\&=2-\dfrac{2}{\log_e3}\text{ square units}\\&\doteq0.1795\text{ square units.}\end{aligned}\]
