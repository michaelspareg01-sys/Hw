Exercise 6G Q12
a \(y=\log_e5+\log_e x^3=\log_e5+3\log_e x\), so \(y'=0+3\times\dfrac1x=\dfrac3x\).
b \(y=\log_e x^{\frac13}=\tfrac13\log_e x\), so \(y'=\tfrac13\times\dfrac1x=\dfrac{1}{3x}\).
c \(y=\ln(2-x)^{\frac12}=\tfrac12\ln(2-x)\), so \(y'=\tfrac12\times\dfrac{-1}{2-x}=\dfrac{-1}{2(2-x)}=\dfrac{1}{2x-4}\).
d \(y=x\log_e2\), and \(\log_e2\) is a constant, so \(y'=\log_e2\).
