Lesson 11C

Using the t-formula to solve equations

Substitute \(t=\tan\tfrac12x\) to turn \(a\sin x+b\cos x=c\) into a quadratic in \(t\), and never lose the solution \(x=180^\circ\).
{{sec:teal:key:Concept 1:the t-formula substitution}}
A different method for a sin x + b cos x = c

Substitute \(t=\tan\tfrac12x\), using \[\sin x=\dfrac{2t}{1+t^2}\qquad\text{and}\qquad\cos x=\dfrac{1-t^2}{1+t^2},\] then multiply through by \(1+t^2\). Everything quickly reduces to a quadratic equation in \(t\).

Advantages: the method is far more automatic, and only a single approximation is involved.

Two disadvantages:

  • The intuition about the LHS being a shifted wave function is lost.
  • If \(x=180^\circ\) happens to be a solution, it will not be found by this method, because \(\tan\tfrac12x\) is not defined at \(x=180^\circ\).

Remember the restriction on \(\tfrac12x\): if \(-180^\circ\le x\le 180^\circ\) then \(-90^\circ\le\tfrac12x\le 90^\circ\); if \(0^\circ\le x\le 360^\circ\) then \(0^\circ\le\tfrac12x\le 180^\circ\).

Worked example 1Keep for homework
Solve \(3\sin x-4\cos x=-2\), for \(-180^\circ\le x\le 180^\circ\), correct to the nearest minute, using the substitution \(t=\tan\tfrac12x\).
Solution

Using \(\sin x=\dfrac{2t}{1+t^2}\) and \(\cos x=\dfrac{1-t^2}{1+t^2}\), the equation becomes

\[\begin{aligned} \dfrac{6t}{1+t^2}-\dfrac{4-4t^2}{1+t^2}&=-2,\quad\text{provided that } x\ne 180^\circ\\ 6t-4+4t^2&=-2-2t^2\\ 6t^2+6t-2&=0\\ 3t^2+3t-1&=0,\quad\text{which has discriminant }\Delta=21\\ \tan\tfrac12x&=-\tfrac12+\tfrac16\sqrt{21}\ \ \text{or}\ \ -\tfrac12-\tfrac16\sqrt{21} \end{aligned}\]

Because \(-180^\circ\le x\le 180^\circ\), the restriction on \(\tfrac12x\) is \(-90^\circ\le\tfrac12x\le 90^\circ\), so

\[\begin{aligned} \tfrac12x&=14.775\,961\ldots^\circ\ \ \text{or}\ \ -51.645\,859\ldots^\circ\quad\text{(only round at the last step)}\\ x&\approx 29^\circ33'\ \ \text{or}\ \ -103^\circ18' \end{aligned}\]

Check \(x=\pm180^\circ\), which the substitution cannot reach: LHS \(=3\times0-4\times(-1)=4\ne-2\), so neither is a solution.

Compare with Worked Example 3 of Lesson 11B, which solved the same equation to the nearest degree.

{{sec:teal:key:Concept 2:the problem when x = 180° is a solution}}
Always be ready to add x = 180°

The substitution \(t=\tan\tfrac12x\) fails when \(x=180^\circ\), because \(\tan 90^\circ\) is undefined. We must always be aware of this possibility, and be prepared to add this answer to the final solution. The situation can easily be recognised in either of these ways:

  • The terms in \(t^2\) cancel out, leaving a linear equation in \(t\).
  • The coefficient of \(\cos x\) is the opposite of the constant term.

Check by substituting \(x=180^\circ\) (where \(\sin x=0\), \(\cos x=-1\)) into the original equation.

Worked example 2Keep for homework
Solve \(7\sin x-4\cos x=4\), for \(0^\circ\le x\le 360^\circ\), by using the substitution \(t=\tan\tfrac12x\).
Solution

Substituting \(t=\tan\tfrac12x\) gives

\[\begin{aligned} \dfrac{14t}{1+t^2}-\dfrac{4-4t^2}{1+t^2}&=4,\quad\text{provided that } x\ne 180^\circ\\ 14t-4+4t^2&=4+4t^2\\ 14t&=8 \end{aligned}\]

Warning: the terms in \(t^2\) have cancelled out, so check \(x=180^\circ\)!

\[\tan\tfrac12x=\tfrac47,\qquad x\approx 59^\circ29'\]

But \(x=180^\circ\) is also a solution, because then LHS \(=7\times0-4\times(-1)=4=\) RHS. So \(x=180^\circ\) or \(x\approx59^\circ29'\).

{{sec:teal:key:Concept 3:choosing a method}}
Solving equations of the form a sin x + b cos x = c
  • The auxiliary-angle method: get the LHS into one of the forms \(R\sin(x+\alpha)\), \(R\sin(x-\alpha)\), \(R\cos(x+\alpha)\) or \(R\cos(x-\alpha)\), then solve the resulting equation.
  • Using the t-formulae: substitute \(t=\tan\tfrac12x\) and then solve the resulting quadratic in \(t\). Be aware that \(x=180^\circ\) may also be a solution if
    • the terms in \(t^2\) cancel out, leaving a linear equation in \(t\), or equivalently,
    • the coefficient of \(\cos x\) is the opposite of the constant term.
Double angles: use t = tan x

For an equation in \(\sin 2x\) and \(\cos 2x\), use the substitution \(t=\tan x\), so that \(\sin 2x=\dfrac{2t}{1+t^2}\) and \(\cos 2x=\dfrac{1-t^2}{1+t^2}\). Now the value that can be lost is \(2x=180^\circ\) (and \(540^\circ\)), that is, \(x=90^\circ\) and \(x=270^\circ\).

Worked example 3t = tan x for a double angle
Solve \(\sin 2x+3\cos 2x=3\), for \(0\le x\le 2\pi\), using the substitution \(t=\tan x\). Give answers correct to 3 decimal places where necessary.
Solution
\[\begin{aligned} \dfrac{2t}{1+t^2}+\dfrac{3(1-t^2)}{1+t^2}&=3,\quad\text{provided that } x\ne\tfrac{\pi}{2},\tfrac{3\pi}{2}\\ 2t+3-3t^2&=3+3t^2\\ 6t^2-2t&=0\\ 2t\,(3t-1)&=0\\ \tan x=0\quad\text{or}\quad\tan x&=\tfrac13 \end{aligned}\]

So \(x=0,\ \pi,\ 2\pi\), or \(x\approx0.322\) or \(x\approx0.322+\pi\approx3.463\).

Check \(x=\tfrac{\pi}{2}\) and \(\tfrac{3\pi}{2}\): \(\sin\pi+3\cos\pi=-3\ne3\), so neither is a solution.

Solutions: \(x=0,\ 0.322,\ \pi,\ 3.463,\ 2\pi\).
