Lesson 13C

Separable differential equations

Solve DEs of the form \(y'=f(x)\,g(y)\) by separating the variables and integrating, always looking first for constant solutions, and dealing carefully with absolute values.
{{sec:teal:key:Concept 1:separating the variables}}
Separable differential equations

A first-order DE is separable if it can be put into the form \(y'=f(x)\,g(y)\).

  • The general case is \(y'=f(x)\,g(y)\), where neither function is a constant.
  • The case \(y'=f(x)\), where \(g(y)=1\), is equivalent to an indefinite integral.
  • The case \(y'=g(y)\), where \(f(x)=1\), is Lesson 13D.

To solve the general case, separate the \(dx\) and \(dy\) and integrate both sides:

\[\dfrac{1}{g(y)}\,dy=f(x)\,dx\qquad\Longrightarrow\qquad\int\dfrac{1}{g(y)}\,dy=\int f(x)\,dx.\]

Justification: dividing \(\dfrac{dy}{dx}=f(x)g(y)\) by \(g(y)\) and integrating with respect to \(x\) gives \(\displaystyle\int\dfrac{1}{g(y)}\dfrac{dy}{dx}\,dx=\int f(x)\,dx\); the chain rule then lets us cancel \(dx\), as with substitution in Chapter 12.

Worked example 1Keep for homework
a Solve \(y'=-2xe^{y}\), and find the solution curve through \((0,0)\).   b Solve \(y'=\dfrac{x}{y}\), and find the solution passing through \(P(4,5)\).
Solution

a Arrange the equation as \(-e^{-y}\,dy=2x\,dx\) and integrate:

\[\begin{aligned}\int-e^{-y}\,dy&=\int2x\,dx\\e^{-y}&=x^2+C\\y&=-\log(x^2+C)\end{aligned}\]

Substituting \((0,0)\): \(0=-\log C\), so \(C=1\) and \(y=-\log(x^2+1)\).

b Separating, \(y\,dy=x\,dx\):

\[\begin{aligned}\int y\,dy&=\int x\,dx\\\tfrac12y^2&=\tfrac12x^2+C\\y^2-x^2&=D\quad(D=2C)\end{aligned}\]

Substituting \(P(4,5)\): \(25-16=D\), so the solution is \(y^2-x^2=9\).

{{sec:teal:key:Concept 2:look for constant solutions first}}
Constant solutions
  • Always check first whether any constant functions \(y=k\) are solutions of the DE: substitute \(y'=0\).
  • This matters because when the DE is solved by separation, constant solutions are often lost through a division by zero.
  • They are horizontal isoclines of horizontal line elements, and are usually horizontal asymptotes of nearby solution curves.

Worked example 2Keep for homework
a Solve \(y'=-xy^2\).   b Find the particular solution given that (i) \(y(1)=\tfrac12\), (ii) \(y(2)=0\).
Solution

a First, the constant function \(y=0\) is trivially a solution. Now, because \(y\ne0\), we can write the DE as \(-y^{-2}\,dy=x\,dx\), and integrating,

\[\int-y^{-2}\,dy=\int x\,dx,\qquad\text{so for some constant }C,\quad y^{-1}=\tfrac12x^2+C.\qquad(*)\]

b (i) Substituting \(y(1)=\tfrac12\) into \((*)\): \(2=\tfrac12+C\), so \(C=\tfrac32\) and \(y^{-1}=\tfrac12x^2+\tfrac32\), that is \(y=\dfrac{2}{x^2+3}\).

(ii) Substituting \(y(2)=0\) into \((*)\) is impossible because of division by zero, but the first solution \(y=0\) satisfies \(y(2)=0\), so it is the required solution.

{{sec:teal:key:Concept 3:dealing with absolute values}}
When the integral is a logarithm

Many solutions involve absolute values, because \(\dfrac1y\) has primitive \(\log|y|\). Although the constant \(C\) may take any value, the power \(e^C\) is never negative and never zero. When interpreting the absolute value signs:

  • Acknowledge that \(e^C\) is always positive.
  • Modify the solution when removing the absolute value signs (the constant can then be positive or negative).
  • Modify the solution again if any constant function is a solution (often this allows the constant to be zero too).

Worked example 3Keep for homework
a Solve the DE \(y'=x(1-y)\).   b Find the particular solution passing through (i) the origin, (ii) \((1,1)\).
Solution

a First, the constant function \(y=1\) is trivially a solution. Now, because \(y\ne1\), we can write the DE as \(\dfrac{dy}{1-y}=x\,dx\), and integrating,

\[\begin{aligned}\int\dfrac{dy}{y-1}&=-\int x\,dx\\\log|y-1|&=-\tfrac12x^2+C,\quad\text{for some constant }C\\|y-1|&=e^{-\frac12x^2+C}\\|y-1|&=Ae^{-\frac12x^2},\quad\text{where }A=e^C\text{ is positive.}\end{aligned}\]

Hence \(y-1=Ae^{-\frac12x^2}\), where \(A\) can be positive or negative. We have already remarked that \(y-1=0\) is a solution of the original DE, so the general solution is \(y=1+Ae^{-\frac12x^2}\), for any constant \(A\).

b (i) Substituting \((0,0)\) gives \(0=1+A\), so \(A=-1\) and \(y=1-e^{-\frac12x^2}\).   (ii) Substituting \((1,1)\) gives \(1=1+Ae^{-\frac12}\), so \(A=0\), giving the constant function \(y=1\).
