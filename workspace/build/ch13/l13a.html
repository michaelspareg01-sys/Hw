Lesson 13A

Differential equations and their solutions

What a differential equation (DE) is, its order, testing solutions by substitution, families of solutions, initial value problems, relations as solutions, and first-order linear DEs.
{{sec:teal:key:Concept 1:differential equations and their order}}
Definitions
  • A differential equation (DE) is an equation that involves a derivative. For example \(y'=-7y\), \(\;y'=1+y^2\), \(\;yy'+x=0\), \(\;y''+49y=0\).
  • The order of a DE is the order of the highest derivative that occurs in it. \(y''+49y=0\) and \(x^2y''-xy'+y=0\) have order 2; the others above have order 1.
  • Its solutions are not numbers but functions (or, more generally, relations in \(x\) and \(y\)). To test whether a function is a solution, substitute it into the DE.
  • An indefinite integral \(\displaystyle\int f(x)\,dx\) is equivalent to the DE \(y'=f(x)\).

Worked example 1Keep for homework
Test whether each function is a solution of the differential equation \(y'=-7y\): a \(y=20e^{7x}\)   b \(y=20e^{-7x}\).
Solution

a Differentiating, \(y'=140e^{7x}\). Substituting into \(y'=-7y\):

\[\text{LHS}=140e^{7x}\qquad\text{RHS}=-7\times20e^{7x}=-140e^{7x}\]

LHS \(\ne\) RHS, so the function is not a solution.

b Differentiating, \(y'=-140e^{-7x}\):

\[\text{LHS}=-140e^{-7x}\qquad\text{RHS}=-7\times20e^{-7x}=-140e^{-7x}\]

LHS \(=\) RHS, so the function is a solution.

The DE involves only algebraic operations, yet its solution is exponential. This is typical of DEs, just as \(\int\frac{dx}{1+x^2}=\tan^{-1}x+C\).

{{sec:teal:key:Concept 2:a family of solutions, and particular solutions}}
General and particular solutions
  • The general solution of a DE normally involves one or more arbitrary constants, giving a family of solutions. The number of arbitrary constants is normally equal to the order of the DE.
  • These constants can be evaluated to give particular solutions if one or more initial conditions (boundary conditions) are known. The problem of finding a particular solution is called an initial value problem (IVP).
  • For a higher-order DE the initial conditions may also involve values of \(y'\), and usually give simultaneous equations.
  • A solution curve (integral curve) may be just one of the connected branches of a function.

Worked example 2Keep for homework
a Show that \(y=Ae^x-x-1\) is a solution of \(y'=x+y\), for all values of \(A\).
b Find the particular solutions (i) through the origin, (ii) with \(y=-2\) when \(x=0\), (iii) through \((0,-1)\).
Solution

a Substituting \(y=Ae^x-x-1\):

\[\text{LHS}=y'=Ae^x-1\qquad \text{RHS}=x+(Ae^x-x-1)=Ae^x-1\]

Hence \(y=Ae^x-x-1\) is a solution for all values of \(A\).

b (i) \(0=A-0-1\), so \(A=1\): \(y=e^x-x-1\).
(ii) \(-2=A-0-1\), so \(A=-1\): \(y=-e^x-x-1\).
(iii) \(-1=A-0-1\), so \(A=0\): \(y=-x-1\).

Substituting \(y'=0\) into the DE gives the line \(x+y=0\): a solution curve has a stationary point only where it crosses this line. Only the curve in (i) does (a minimum at the origin).

Worked example 3Keep for homework
It is known that \(y=A\sin 7x+B\cos 7x\) is a solution of \(y''=-49y\) for all \(A\) and \(B\). Find the solution for which \(y(0)=1\) and \(y'(0)=14\).
Solution
\[y=A\sin 7x+B\cos 7x,\qquad y'=7A\cos 7x-7B\sin 7x\]

When \(x=0\), \(y=1\), so \(1=0+B\). When \(x=0\), \(y'=14\), so \(14=7A+0\). Hence \(A=2\), \(B=1\), and \(y=2\sin 7x+\cos 7x\).

{{sec:teal:key:Concept 3:relations as solutions, and linear DEs}}
Relations can be solutions

Relations that are not functions can be solutions of DEs, with the usual arbitrary constants and families of curves. Forming the DE from such a relation uses the chain rule, for example \(\dfrac{d}{dx}(y^2)=2yy'\) and \(\dfrac{d}{dx}(xy)=y+xy'\).

First-order linear DEs
  • A first-order DE is linear if it can be put into the form \(y'+f(x)\,y=g(x)\).
  • An indefinite integral is equivalent to a first-order linear DE with \(f(x)=0\): \(y'=g(x)\).
  • An exponential growth DE \(y'-ky=0\) is first-order linear with \(g(x)=0\) and \(f(x)\) constant.

For example, \(y'=\dfrac{y}{x}\) is linear (it is \(y'-\tfrac1x y=0\)), but \(y'=\dfrac{x}{y}\) is not (it becomes \(yy'=x\)).
