Lesson 13B

Slope fields

Draw and read slope fields for DEs of the form \(y'=G(x,y)\), sketch solution curves, use isoclines, and recognise constant (equilibrium) solutions.
{{sec:teal:key:Concept 1:drawing a slope field}}
Slope fields (gradient fields, direction fields)

A slope field can only be drawn for a first-order DE that can be written with \(y'\) as the subject, \(y'=G(x,y)\). At each point on a solution curve the tangent has gradient \(G(x,y)\), so we draw a short line element with that gradient.

  • Choose a suitable grid of points in the plane.
  • Draw up a table showing the gradients at these grid points.
  • Display these gradients by short tilted line elements of a fixed length, centred at the grid points.

Each line element shows only a gradient: it has no direction, and its length has no significance.

Example: y′ = ½x

All the rows of the table of slopes are the same, because \(y\) is not involved. The slope field suggests a family of parabolas with the \(y\)-axis as axis of symmetry, all vertical translations of each other. Indeed, integrating gives \(y=\tfrac14x^2+C\).

Every vertical line is an isocline (a curve through points where the gradient is the same). The \(y\)-axis is special: the gradient is zero there, so every solution curve has a stationary point where it crosses the \(y\)-axis.

{{sec:teal:key:Concept 2:sketching solution curves and reading a field}}
Sketching a solution curve (integral curve)
  • Place a pencil on the diagram and follow the gradients. Two solution curves can never cross (apart from strange singularities), because the gradient at each point can only have one value.
  • This is not an accurate procedure. In particular, asymptotic behaviour may not be clear.
  • If there is an initial condition, start there and draw in both directions. Otherwise draw about three representative curves.
Things to look for in a slope field
  • Where the slope is zero (horizontal line elements): solution curves have stationary points there.
  • Where the line elements slope upwards (positive) and downwards (negative): this tells where curves increase and decrease.
  • Isoclines, and any isocline whose line elements lie along the isocline itself: such a line is a solution curve, no other solution crosses it, and nearby curves often have it as an asymptote.
  • Vertical line elements, where the DE has a division by zero.

These features are the quickest way to eliminate wrong options when matching a DE to a slope field.

Worked example 1Keep for homework
a Construct a slope field for \(y'y+x=0\).   b What family of curves look as if they are solution curves?   c Check by differentiation.
Solution

a Solving for \(y'\) gives \(y'=-\dfrac{x}{y}\), provided that \(y\ne0\). On the \(x\)-axis the line elements are drawn vertical, because there they arise from division of a non-zero number by zero. The origin has no line element at all.

The gradient is zero on the \(y\)-axis (excluding the origin), negative in quadrants 1 and 3 and positive in 2 and 4. The isoclines are all the lines through the origin.

b The solution curves look like circles with centre the origin.

c Testing \(x^2+y^2=r^2\): differentiating, \(2x+2yy'=0\), as required.

{{sec:teal:key:Concept 3:isoclines that are solutions, and constant solutions}}
An isocline that is an asymptote

For \(y'=x+y\), every line \(x+y=c\) is an isocline (gradient \(c\)). The isocline \(y=-x-1\) is exceptional: its gradient \(-1\) matches the line elements along it, so it is itself a solution. No other solution crosses it; the curves above it curl upwards, those below curl downwards, and all are asymptotic to it on the left.

Constant solutions are horizontal asymptotes

Any constant solution \(y=k\) stands out on a slope field as a horizontal line of horizontal line elements. It is an isocline, and it divides the solutions into those above and those below. Usually many solution curves have it as a horizontal asymptote on the left or right.

A constant solution that is an asymptote on the right is a stable equilibrium; one that is an asymptote on the left is an unstable equilibrium.

Worked example 2Keep for homework
For the DE \(y'=\tfrac14(y-2)(y+2)\): a identify the constant solutions from the slope field; b show that they are solutions; c if the horizontal axis is time, describe the behaviour of solution curves near each constant solution.
Solution

a The horizontal isoclines \(y=2\) and \(y=-2\) stand out because both consist of points where the gradient is zero.

b Substituting \(y=2\) or \(y=-2\) gives LHS \(=y'=0\) and RHS \(=0\).

c As time increases, the curves between and below the lines approach \(y=-2\): this is a stable equilibrium. A curve starting just above \(y=2\) goes up without bound, and one just below goes down towards \(y=-2\), so \(y=2\) is an unstable equilibrium.
