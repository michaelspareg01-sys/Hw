Lesson 4J

Primitive functions

This lesson reverses the process of differentiation and asks, ‘What can we say about a function if we know its derivative?’ Any two functions with the same derivative differ only by a constant, so the answer is a whole family of functions, the primitive \(F(x)+C\). The rule ‘increase the index by 1 and divide by the new index’ finds primitives of powers of \(x\), and of powers of a linear function \(ax+b\). An initial condition then picks out one member of the family. The results of this lesson are needed when integration is introduced in Lesson 5A.
{{sec:teal:key:Concept 1:functions with the same derivative}}
Reversing differentiation

This section reverses the process of differentiation and asks, ‘What can we say about a function if we know its derivative?’ The results of this section will be needed when integration is introduced in Chapter 5 (Lessons 5A–5I of this pack).

This topic was briefly mentioned in Section 9D of the Year 11 book, but without any terminology or formulae, and we begin the discussion again here.

Functions with the same derivative

Many different functions may all have the same derivative. For example, all these functions have the same derivative \(2x\):

\[x^2,\qquad x^2+3,\qquad x^2-2,\qquad x^2+4\tfrac12,\qquad x^2-\pi.\]

The derivative of a constant is zero, so the constant term adds nothing to the derivative. For example, \(\dfrac{d}{dx}\big(x^2+3\big)=2x+0=2x\) and \(\dfrac{d}{dx}\big(x^2-\pi\big)=2x-0=2x\).

These functions are all the same apart from a constant term. This is true generally: any two functions with the same derivative differ only by a constant.

14 Functions with the same derivative

A If a function \(f(x)\) has derivative zero in an interval \(a\lt x\lt b\), then \(f(x)\) is a constant function in \(a\lt x\lt b\).

B If \(f'(x)=g'(x)\) for all \(x\) in an interval \(a\lt x\lt b\), then \(f(x)\) and \(g(x)\) differ by a constant in \(a\lt x\lt b\).

Proof

A Because the derivative is zero, the gradient of the curve is zero throughout the interval. The curve is therefore a horizontal straight line, and \(f(x)\) is a constant function.

B Take the difference between \(f(x)\) and \(g(x)\) and apply part A.

\[\begin{aligned}\text{Let}\quad h(x)&=f(x)-g(x).\\\text{Then}\quad h'(x)&=f'(x)-g'(x)\\&=0,\qquad\text{for all }x\text{ in the interval }a\lt x\lt b.\\\text{Hence by part A,}\quad h(x)&=C,\qquad\text{where }C\text{ is a constant,}\\\text{so}\quad f(x)-g(x)&=C,\qquad\text{as required.}\end{aligned}\]

The line \(h'(x)=f'(x)-g'(x)\) holds because the derivative of a difference is the difference of the derivatives. The next line is zero because \(f'(x)=g'(x)\) for all \(x\) in the interval.

Notice that both parts of Box 14 are stated for an interval \(a\lt x\lt b\), with no gaps in it.

Show that the functions \(x^2\), \(x^2+3\), \(x^2-2\), \(x^2+4\tfrac12\) and \(x^2-\pi\) all have the same derivative \(2x\).
Solution

Differentiate each function. The derivative of \(x^2\) is \(2x\), and the derivative of each constant term is zero.

\(\dfrac{d}{dx}\big(x^2\big)=2x\) \(\dfrac{d}{dx}\big(x^2+3\big)=2x+0=2x\) \(\dfrac{d}{dx}\big(x^2-2\big)=2x-0=2x\) \(\dfrac{d}{dx}\big(x^2+4\tfrac12\big)=2x+0=2x\) \(\dfrac{d}{dx}\big(x^2-\pi\big)=2x-0=2x\)

The five functions are the same apart from their constant terms, and any two of them differ by a constant. For example, \(\big(x^2+3\big)-\big(x^2-2\big)=5\).

{{sec:teal:key:Concept 2:families of curves, initial conditions and primitives}}
The family of curves with the same derivative

Continuing with the very first example, the various functions whose derivatives are \(2x\) are all of the form

\[f(x)=x^2+C,\qquad\text{where }C\text{ is a constant.}\]

By taking different values of the constant \(C\), these functions form an infinite family of curves, each consisting of the parabola \(y=x^2\) translated upwards or downwards (see the worked example below).

Initial or boundary conditions

If we know also that the graph of the function passes through a particular point, say \((2,7)\), then we can evaluate the constant \(C\) by substituting the point into \(f(x)=x^2+C\):

\[\begin{aligned}7&=2^2+C\\7&=4+C\\C&=3.\end{aligned}\]

Thus \(C=3\) and hence \(f(x)=x^2+3\).

In place of the infinite family of functions, there is now a single function.

Such an extra condition is called an initial condition or boundary condition.

Primitives

We need a suitable name for the result of this reverse process. The words primitive and anti-derivative are both used.

15 A primitive of a function
  • A function \(F(x)\) is called a primitive or an anti-derivative of \(f(x)\) if the derivative of \(F(x)\) is \(f(x)\), \[F'(x)=f(x).\]
  • If \(F(x)\) is any primitive of \(f(x)\), then the general primitive of \(f(x)\) is \[F(x)+C,\qquad\text{where }C\text{ is a constant.}\]
A primitive and the primitive

The general primitive of \(f(x)\) is also called just the primitive of \(f(x)\). For example, each of these functions is a primitive of \(x^2+1\),

\[\tfrac13x^3+x,\qquad\tfrac13x^3+x+7,\qquad\tfrac13x^3+x-13,\qquad\tfrac13x^3+x+4\pi,\]

because the derivative of each one is \(x^2+1\). For example,

\[\dfrac{d}{dx}\big(\tfrac13x^3+x+7\big)=\tfrac13\times3x^2+1+0=x^2+1.\]

Whereas the primitive of \(x^2+1\) is \(\tfrac13x^3+x+C\), where \(C\) is a constant.

{{sec:teal:key:Concept 3:a rule for finding primitives}}
Reversing the derivative of \(x^{n+1}\)

We have seen that a primitive of \(x\) is \(\tfrac12x^2\), and a primitive of \(x^2\) is \(\tfrac13x^3\). Reversing the formula

\[\dfrac{d}{dx}\big(x^{n+1}\big)=(n+1)x^n\]

gives the general rule. Dividing both sides by \(n+1\), which is allowed only when \(n+1\ne0\), that is, when \(n\ne-1\),

\[\dfrac{d}{dx}\Big(\dfrac{x^{n+1}}{n+1}\Big)=\dfrac{(n+1)x^n}{n+1}=x^n.\]

So \(\dfrac{x^{n+1}}{n+1}\) is a primitive of \(x^n\), and by Box 15 the general primitive is \(\dfrac{x^{n+1}}{n+1}+C\).

16 Finding primitives
\[\begin{aligned}&\text{If}\quad\dfrac{dy}{dx}=x^n,\quad\text{where }n\ne-1,\\&\text{then}\quad y=\dfrac{x^{n+1}}{n+1}+C,\quad\text{for some constant }C.\end{aligned}\]

‘Increase the index by 1 and divide by the new index.’

Sums, multiples and constants

Derivatives of sums and multiples are found one term at a time (revision, Year 11, 8C), so primitives are found one term at a time too:

  • A constant factor stays where it is. For example, a primitive of \(5x^3\) is \(5\times\dfrac{x^4}{4}=\tfrac54x^4\).
  • A constant term \(k\) is \(kx^0\), so a primitive of it is \(k\times\dfrac{x^1}{1}=kx\). For example, a primitive of 7 is \(7x\).
  • Only one constant \(C\) is needed at the end, because the sum of several constants is a constant.
  • Expand a product of brackets first, so that each term is a multiple of a power of \(x\).
Check a primitive by differentiating it

Differentiate your answer. You should get back the function you started with. For example, \(\dfrac{d}{dx}\big(\tfrac54x^4+7x+C\big)=5x^3+7\).

{{sec:teal:key:Concept 4:negative and fractional indices}}
Rewrite with indices first

The rule in Box 16 works for every index \(n\) except \(n=-1\), including negative and fractional indices. So first rewrite reciprocals of powers with negative indices, and surds with fractional indices (revision, Year 11, 7A–7B). Then apply the rule.

  • Dividing by a negative index. For example, \(\dfrac{x^{-1}}{-1}=-x^{-1}=-\dfrac1x\).
  • Dividing by a fractional index. Dividing by \(\tfrac32\) is the same as multiplying by \(\tfrac23\), so \(\dfrac{x^{\frac32}}{\frac32}=\tfrac23x^{\frac32}\).
  • Convert the answer back to fraction form (without negative indices) when the question asks.

{{sec:teal:key:Concept 5:the linear extension}}
Reversing the chain rule for \((ax+b)^{n+1}\)

By the chain rule (revision, Year 11, 8G), with \(u=ax+b\) and \(\dfrac{du}{dx}=a\),

\[\dfrac{d}{dx}(ax+b)^{n+1}=a(n+1)(ax+b)^n.\]

Reversing this formula gives the rule below. Dividing both sides by \(a(n+1)\), which is allowed when \(a\ne0\) and \(n\ne-1\),

\[\dfrac{d}{dx}\Big(\dfrac{(ax+b)^{n+1}}{a(n+1)}\Big)=\dfrac{a(n+1)(ax+b)^n}{a(n+1)}=(ax+b)^n.\]
17 Extension to powers of linear functions
\[\begin{aligned}&\text{If}\quad\dfrac{dy}{dx}=(ax+b)^n,\quad\text{where }n\ne-1,\\&\text{then}\quad y=\dfrac{(ax+b)^{n+1}}{a(n+1)}+C,\quad\text{for some constant }C.\end{aligned}\]

‘Increase the index by 1, then divide by the new index and by the coefficient of \(x\).’

Watch the coefficient of \(x\)
  • In \((1-3x)^6\) the coefficient of \(x\) is \(a=-3\), so we divide by \(-3\). In \((x+1)^4\) the coefficient is \(a=1\).
  • Box 17 is only for a power of a linear function \(ax+b\). For a power of something like \(x^2+1\), expand the brackets first for now (Lesson 5I deals with some of these).

{{sec:teal:key:Concept 6:finding the primitive, given an initial condition}}
Using an initial condition

If the derivative of a function is known, plus an initial condition (or boundary condition), then substitute the condition into the general primitive to find the constant, and hence the original function.

18 Finding a function, given its derivative and an initial condition
  • First find the primitive, taking care to include the constant of integration.
  • Then substitute the known value of the function to work out the constant.

Worked example 29Keep for homework
Given that \(\dfrac{dy}{dx}=6x^2+1\), and \(y=12\) when \(x=2\), find \(y\) as a function of \(x\).
Solution

We know that \(\dfrac{dy}{dx}=6x^2+1\).

So \(\begin{aligned}[t]y&=6\times\dfrac{x^3}{3}+x+C\\&=2x^3+x+C,\end{aligned}\) for some constant \(C\).

Substituting the condition into this primitive, \(\begin{aligned}[t]12&=2\times2^3+2+C\\12&=16+2+C,\end{aligned}\)

so \(C=-6\), and hence \(y=2x^3+x-6\).

{{sec:teal:key:Concept 7:starting from the second derivative}}
Two primitives, two constants

If the second derivative \(f''(x)\) is known, take the primitive twice. The first primitive gives \(f'(x)\) with a constant \(C\). The second primitive gives \(f(x)\) with a second constant \(D\). The primitive of the constant \(C\) is \(Cx\), so \(f(x)\) has the form \(\big(\cdots\big)+Cx+D\).

Two conditions are then needed to find the two constants:

  • two values of the function, as in Worked example 30, or
  • one value of \(f'(x)\) and one value of \(f(x)\). Then use the condition on \(f'(x)\) to find \(C\) before taking the second primitive.

Worked example 30Keep for homework
Given that \(f''(x)=12(x-1)^2\), and \(f(0)=f(1)=0\), find \(f(4)\).
Solution

We know that \(f''(x)=12(x-1)^2\).

Taking the primitive, \(\begin{aligned}[t]f'(x)&=12\times\dfrac{(x-1)^3}{3\times1}+C\\&=4(x-1)^3+C,\end{aligned}\) for some constant \(C\).

Taking the primitive again, \(\begin{aligned}[t]f(x)&=4\times\dfrac{(x-1)^4}{4\times1}+Cx+D\\&=(x-1)^4+Cx+D,\end{aligned}\) for some constant \(D\).

Because \(f(0)=0\), \(\begin{aligned}[t]0&=(0-1)^4+C\times0+D\\0&=1+0+D\\D&=-1.\end{aligned}\)

Because \(f(1)=0\), \(\begin{aligned}[t]0&=(1-1)^4+C\times1+D\\0&=0+C-1.\end{aligned}\)

Hence \(C=1\), so \(f(x)=(x-1)^4+x-1\), and \(\begin{aligned}[t]f(4)&=(4-1)^4+4-1\\&=81+4-1\\&=84.\end{aligned}\)
