Lesson 5H

The trapezoidal rule

Some definite integrals cannot be found exactly with a primitive, and some functions are known only from a table of measured values. This lesson approximates such integrals by replacing the curve by chords, so that the region becomes a set of trapezia. It covers the rule with one subinterval, splitting the interval into several equal subintervals, how the concavity of the curve tells you whether the rule overestimates or underestimates, the single formula for \(n\) subintervals, and doing the calculation on a spreadsheet.
{{sec:teal:key:Concept 1:the trapezoidal rule, and subdividing the interval}}
Why approximate?

Methods of approximating definite integrals become necessary when exact calculations using primitives are not possible. This can happen for two reasons.

  • The primitives of many important functions cannot be written down in a formula suitable for calculation. This is the case for the important normal distribution in Chapter 16.
  • Some values of a function may be known only from experiments, and the function formula may be unknown.
The trapezoidal rule

Besides taking upper and lower rectangles, the most obvious way to approximate an integral is to replace the curve by a straight line, that is, by a chord joining \(\big(a,f(a)\big)\) and \(\big(b,f(b)\big)\). The resulting region is a trapezium, so this approximation method is called the trapezoidal rule.

Consider the trapezium in the diagram to the right.

{{svg:c5h_one}}
\[\begin{aligned}\text{Here}\qquad\text{width}&=b-a,\\ \text{and}\quad\text{average of parallel sides}&=\frac{f(a)+f(b)}{2}.\\ \text{Hence}\quad\text{area of trapezium}&=\text{width}\times\text{average of parallel sides}\\&=\frac{b-a}{2}\Big(f(a)+f(b)\Big).\end{aligned}\]

The area of this trapezium is taken as an approximation of the integral.

18 The trapezoidal rule using one subinterval

Let \(f(x)\) be a function that is continuous in the closed interval \([a,b]\).

  • Approximating the curve from \(x=a\) to \(x=b\) by a chord allows the region under the curve to be approximated by a trapezium, giving \[\int_a^b f(x)\,dx\doteqdot\frac{b-a}{2}\Big(f(a)+f(b)\Big).\]
  • If the function is linear, then the chord coincides with the curve and the formula is exact.
  • Always start a trapezoidal-rule calculation by constructing a table of values.
Where the formula comes from
  • The area of a trapezium is \(\tfrac12(a+b)h\), where \(a\) and \(b\) are the lengths of the two parallel sides and \(h\) is the distance between them. Here the parallel sides are the two vertical lines at \(x=a\) and \(x=b\), with lengths \(f(a)\) and \(f(b)\), and the distance between them is the width \(b-a\) along the \(x\)-axis.
  • So the area is \(\tfrac12\big(f(a)+f(b)\big)(b-a)\), which is the same as \(\dfrac{b-a}{2}\big(f(a)+f(b)\big)\).
  • The sign \(\doteqdot\) means ‘is approximately equal to’. The only error comes from the gap between the curve and the chord.
Subdividing the interval

Given an integral over an interval \([a,b]\), we can split that interval \([a,b]\) up into a number of subintervals and apply the trapezoidal rule to each subinterval in turn. This will usually improve the accuracy of the approximation.

Here is the method applied to the reciprocal function \(y=\dfrac1x\), whose primitive we will establish in Chapter 6.

How the pieces fit together

Splitting at the points between \(a\) and \(b\) uses the dissection of the interval (Box 7 of Lesson 5C). Each smaller integral is then replaced by the area of one trapezium, and the trapezium areas are added. The chords of the smaller trapezia hug the curve more closely, which is why the accuracy usually improves.

Solution

Always begin with a table of values of the function.

\(x\)\(1\)\(2\)\(3\)\(4\)\(5\)
\(\dfrac1x\)\(1\)\(\tfrac12\)\(\tfrac13\)\(\tfrac14\)\(\tfrac15\)

a One application of the trapezoidal rule, using the whole interval as the subinterval, requires just two values of the function.

\[\begin{aligned}\int_1^5\frac1x\,dx&\doteqdot\frac{5-1}{2}\times\Big(f(1)+f(5)\Big)\\&\doteqdot2\times\big(1+\tfrac15\big)\\&\doteqdot2\tfrac25\end{aligned}\]
{{svg:c5h_e32}}

b Four applications of the trapezoidal rule require five values of the function. Dividing the interval \(1\le x\le5\) into four equal subintervals,

\[\int_1^5\frac1x\,dx=\int_1^2\frac1x\,dx+\int_2^3\frac1x\,dx+\int_3^4\frac1x\,dx+\int_4^5\frac1x\,dx.\]

Each subinterval has width 1, so applying the trapezoidal rule to each integral,

\[\begin{aligned}\int_1^5\frac1x\,dx&\doteqdot\tfrac12\Big(f(1)+f(2)\Big)+\tfrac12\Big(f(2)+f(3)\Big)\\&\qquad+\tfrac12\Big(f(3)+f(4)\Big)+\tfrac12\Big(f(4)+f(5)\Big)\\&\doteqdot\tfrac12\big(\tfrac11+\tfrac12\big)+\tfrac12\big(\tfrac12+\tfrac13\big)+\tfrac12\big(\tfrac13+\tfrac14\big)+\tfrac12\big(\tfrac14+\tfrac15\big)\\&\doteqdot1\tfrac{41}{60}.\end{aligned}\]
Steps the book skips: Worked example 32

a The width is \(5-1=4\), so \(\dfrac{5-1}{2}=2\). Then \(1+\tfrac15=\tfrac65\), and \(2\times\tfrac65=\tfrac{12}{5}=2\tfrac25\).

b Work out each trapezium, then add over the common denominator 120:

\[\begin{aligned}&\tfrac12\big(\tfrac11+\tfrac12\big)+\tfrac12\big(\tfrac12+\tfrac13\big)+\tfrac12\big(\tfrac13+\tfrac14\big)+\tfrac12\big(\tfrac14+\tfrac15\big)\\&\quad=\tfrac12\times\tfrac32+\tfrac12\times\tfrac56+\tfrac12\times\tfrac{7}{12}+\tfrac12\times\tfrac{9}{20}\\&\quad=\tfrac34+\tfrac{5}{12}+\tfrac{7}{24}+\tfrac{9}{40}\\&\quad=\tfrac{90}{120}+\tfrac{50}{120}+\tfrac{35}{120}+\tfrac{27}{120}\\&\quad=\tfrac{202}{120}\\&\quad=1\tfrac{41}{60}.\end{aligned}\]

The second answer is smaller than the first. The four chords lie closer to the curve than the single chord does, as the diagram shows.

Concavity and the trapezoidal rule

The curve in the example above is concave up, so every chord is above the curve, and every approximation found using the trapezoidal rule is therefore greater than the integral.

Similarly, if a curve is concave down, then every chord is below the curve, and every trapezoidal-rule approximation is less than the integral. The second derivative can be used to test concavity.

19 Concavity and the trapezoidal rule
  • If the curve is concave up, the trapezoidal rule overestimates the integral.
  • If the curve is concave down, the trapezoidal rule underestimates the integral.
  • If the curve is linear, the trapezoidal rule gives the exact value of the integral.

The second derivative \(\dfrac{d^2y}{dx^2}\) can be used to test the concavity.

Recall: concavity (Year 11)
  • If \(f''(x)>0\) throughout an interval, the curve is concave up there: it bends upwards, and each chord lies above the curve. If \(f''(x)<0\) throughout the interval, the curve is concave down, and each chord lies below the curve.
  • A chord above the curve gives a trapezium that holds the whole region plus a thin sliver, so its area is too big. A chord below the curve leaves a sliver out, so its area is too small.
  • Box 19 needs one concavity across the whole interval. If the concavity changes inside the interval, the errors on the two sides can partly cancel, and the box gives no conclusion.

Solution

a Construct a table of values for \(y=200x-x^4\).

\[\begin{aligned}\int_1^5(200x-x^4)\,dx&\doteqdot\frac{5-1}{2}\times\Big(f(1)+f(5)\Big)\\&\doteqdot2\times(199+375)\\&\doteqdot1148\end{aligned}\]
\(x\)\(1\)\(5\)
\(y\)\(199\)\(375\)

b The function is \(y=200x-x^4\).

Differentiating, \(y'=200-4x^3\)
and \(y''=-12x^2\).

Because \(y''=-12x^2\) is negative throughout the interval \(1\le x\le5\), the curve is concave down throughout this interval.
Hence the trapezoidal rule underestimates the integral.

A formula for multiple applications of the trapezoidal rule

When the trapezoidal rule is being applied two or three times, it is easier to perform the two or three calculations required. These separate calculations also reinforce the meaning of the approximation, and help to gain an intuitive understanding of the accuracy of the estimates.

But increasing accuracy with the trapezoidal rule requires larger numbers of applications of the rule, and this can quickly become tedious. Let us then develop a single formula that splits an integral into \(n\) subintervals of equal width and applies the trapezoidal rule to each. Anyone writing a program or using a spreadsheet to estimate integrals would want to do this.

The first step is to divide the interval \([a,b]\) into \(n\) equal subintervals, each of width \(h\), like this:

{{svg:c5h_div}}
Deriving the formula

There are \(n+1\) points altogether, and they divide the interval into \(n\) equal subintervals. The endpoints are \(a=x_0\) and \(b=x_n\), and the \(n-1\) division points in between are \(x_1\), \(x_2\), …, \(x_{n-1}\).

There are \(n\) subintervals, so \(nh=b-a\), and the width \(h\) of each subinterval is

\[h=\frac{b-a}{n}.\]

Thus starting with \(a=x_0\), the successive values of the division points are

\[\begin{aligned}x_0&=a\\x_1&=a+h\\x_2&=a+2h\\&\ \ \vdots\end{aligned}\]
\[\begin{aligned}x_{n-2}&=a+(n-2)h\\x_{n-1}&=a+(n-1)h\\x_n&=a+nh=a+(b-a)=b\end{aligned}\]

That is, \(x_r=a+rh\), for \(r=0,1,2,\ldots,n-1,n\).
Now we can apply the trapezoidal rule to each subinterval in turn,

\[\begin{aligned}\int_a^b f(x)\,dx&=\int_a^{x_1}f(x)\,dx+\int_{x_1}^{x_2}f(x)\,dx+\cdots\\&\qquad+\int_{x_{n-2}}^{x_{n-1}}f(x)\,dx+\int_{x_{n-1}}^{b}f(x)\,dx\\&\doteqdot\frac h2\Big(f(a)+f(x_1)\Big)+\frac h2\Big(f(x_1)+f(x_2)\Big)+\cdots\\&\qquad+\frac h2\Big(f(x_{n-2})+f(x_{n-1})\Big)+\frac h2\Big(f(x_{n-1})+f(b)\Big)\\&\doteqdot\frac h2\Big(f(a)+2f(x_1)+2f(x_2)+\cdots+2f(x_{n-1})+f(b)\Big).\end{aligned}\]
20 Trapezoidal-rule formula using \(n\) subintervals

Let \(f(x)\) be a function that is continuous in the closed interval \([a,b]\). Then

\[\int_a^b f(x)\,dx\doteqdot\frac h2\Big(f(a)+2f(x_1)+2f(x_2)+\cdots+2f(x_{n-1})+f(b)\Big)\]

where \(h=\dfrac{b-a}{n}\) and \(x_r=a+rh\), for \(r=1,2,\ldots,n-1\).

A common rearrangement

A common rearrangement of this formula, using three sets of nested brackets, is

\[\int_a^b f(x)\,dx\doteqdot\frac{b-a}{2n}\bigg(f(a)+f(b)+2\Big(f(x_1)+f(x_2)+\cdots+f(x_{n-1})\Big)\bigg).\]
The steps of the derivation, filled in
  • Each subinterval has width \(h\), so each trapezium has area \(\dfrac h2\times(\text{left height}+\text{right height})\).
  • Each division point \(x_1,\ldots,x_{n-1}\) is the right-hand end of one subinterval and the left-hand end of the next. So each of \(f(x_1),\ldots,f(x_{n-1})\) appears in two trapezia, and the terms collect to \(2f(x_1),\ldots,2f(x_{n-1})\). The end values \(f(a)\) and \(f(b)\) each appear in only one trapezium.
  • For the rearrangement, \(\dfrac h2=\dfrac{b-a}{n}\div2=\dfrac{b-a}{2n}\). Then the two end values are written first, and the factor 2 is taken out of the middle terms.
  • Check the count: \(n\) subintervals use \(n+1\) function values. For example, four subintervals use five function values.
Using the formula for the trapezoidal rule

The formula may look complicated at first sight, but it is actually quite straightforward to use, provided that:

  • We begin with a sensible value of the width \(h\) of each subinterval.
  • We construct a clear table of values to work from.

{{sec:teal:key:Concept 4:using a spreadsheet for calculations}}
Using a spreadsheet for calculations

The authors used a spreadsheet for all the calculations above. The trapezoidal-rule formula is well suited for machine computation. The next worked example shows how to use an Excel spreadsheet to carry out such a calculation, but any spreadsheet can be used. Note that:

  • Excel commands and procedures have been changing over successive versions.
  • Mac users will need some adjustments, particularly when implementing the ‘fill down’ and ‘fill right’ commands.

The calculation involves the integration of \(\dfrac{e^{-\frac12x^2}}{\sqrt{2\pi}}\). We will see in Chapter 16 that this function is the probability density function of the normal distribution, and is the most important function in statistics. There is no simple equation for its primitive, so approximations are always necessary.

Reading the spreadsheet
  • Row 2 holds the \(x\)-values \(x_0,x_1,\ldots,x_{10}\), row 3 holds the function values, and row 4 holds each function value times its weight in Box 20: weight 1 for the two end values and weight 2 for the nine middle values.
  • The sum of row 4 is the big bracket in Box 20, and the last step multiplies it by \(\tfrac12h\).
  • No spreadsheet? A calculator gives the same table one value at a time. The spreadsheet just does all the values at once.

Worked example 35From the text: keep for homework
Let \(\phi(x)=\dfrac{e^{-\frac12x^2}}{\sqrt{2\pi}}\). Approximate the integral \(\displaystyle\int_0^1\phi(x)\,dx\) using the trapezoidal rule with 10 subintervals.
(The symbol \(\phi\) is the lower case Greek letter ‘phi’, corresponding to Latin \(f\).)
Solution

In these instructions, we enter a formula into a cell by typing the \(=\) sign as the first character. The cell in column D and row 3 is labelled D3, and in formulae, this refers to its contents. Normally leave the top row clear for later titles.

  1. On a new sheet in Excel, enter 0 into Cell A2 and press Enter.
    Select Cell B2 and type =0.1+A2 and press Enter.
    Cell B2 should now show 0.1.
  2. Select Cells B2:K2 and press Ctrl+R to ‘fill right’.
    Cells C2:K2 should now show 0.2, 0.3, …, 1.
  3. Type =EXP(-A2*A2/2)/SQRT(2*PI()) into Cell A3.
    Cell A3 should now show \(\phi(0)=0.398942\).
  4. Select Cells A3:K3 and press Ctrl+R to ‘fill right’.
    Cells B3:K3 should now show \(\phi(0.1)=0.396953\), …, \(\phi(1)=0.241971\).

    We now have the table of values for the function \(\phi(x)\), and we need to add

    \[\phi(0)+2\phi(0.1)+2\phi(0.2)+\cdots+2\phi(0.9)+\phi(1)\]
  5. Select Cell A4 and enter =A3. This should duplicate the value in A3.
    Select Cell K4 and enter =K3. Again, this duplicates the value in K3.
    Select Cell B4 and enter =2*B3. This should double the value in B3.
    Select Cells B4:J4 and press Ctrl+R to ‘fill right’.
    Add the row by selecting Cell L4 and typing =SUM(A4:K4).

    In this case, \(h=0.1\) so we multiply by \(\tfrac12h=0.05\).

  6. Select Cell L5 and type =L4*0.05. This shows the final answer.

Hence \(\displaystyle\int_0^1\phi(x)\,dx\doteqdot0.341\). We shall find in Chapter 16 that this is approximately the probability that a score in a normal distribution lies between the mean 0 and one standard deviation above the mean. The correct value to four decimal places is 0.3413. We will see in Chapter 16 that the curve is concave down in the interval \([0,1]\), which explains why our estimate is a little smaller than it should be.

Possible spreadsheet projects

It is possible to program a spreadsheet so that the number of subintervals can be entered as a single variable. The construction of such a program and similar programs could be incorporated into a longer project examining the usefulness and accuracy of the trapezoidal rule, or examining some physical phenomena.

In the next diagram, it is clear that in parts of the graph where there is a lot of activity, the subintervals should be quite narrow, whereas in other calmer parts they can be far wider. Such variability could also be incorporated into the spreadsheet and its formulae.
