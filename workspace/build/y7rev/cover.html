This pack holds more than one lesson's worth of questions, so choose questions to suit the student. The questions marked ★ make a suggested core set for a 2-hour lesson. The core set leans towards the harder questions. Most questions are taken word for word from ICE-EM Mathematics 7 (3rd edition), and the source is shown beside each one. Questions marked ‘Pack question’ were written for this pack, to cover question types from the Year 7 tasks that the textbook does not have. Times are a guide for a typical Year 7 student.
