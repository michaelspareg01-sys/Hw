Tutor demo.

a Using \(\sin^2x=\tfrac12-\tfrac12\cos2x\),

\[\begin{aligned}\int_{0}^{\frac{\pi}{4}}\sin^2x\,dx&=\int_{0}^{\frac{\pi}{4}}\big(\tfrac12-\tfrac12\cos2x\big)\,dx\\&=\Big[\tfrac12x-\tfrac14\sin2x\Big]_{0}^{\frac{\pi}{4}}\\&=\big(\tfrac{\pi}{8}-\tfrac14\sin\tfrac{\pi}{2}\big)-\big(0-\tfrac14\sin0\big)\\&=\big(\tfrac{\pi}{8}-\tfrac14\big)-\big(0-0\big)\\&=\tfrac{\pi}{8}-\tfrac14\end{aligned}\]

b Using \(\cos^2\tfrac12x=\tfrac12+\tfrac12\cos x\),

\[\begin{aligned}\int_{0}^{\frac{2\pi}{3}}\cos^2\tfrac12x\,dx&=\int_{0}^{\frac{2\pi}{3}}\big(\tfrac12+\tfrac12\cos x\big)\,dx\\&=\Big[\tfrac12x+\tfrac12\sin x\Big]_{0}^{\frac{2\pi}{3}}\\&=\big(\tfrac{\pi}{3}+\tfrac12\sin\tfrac{2\pi}{3}\big)-\big(0+\tfrac12\sin0\big)\\&=\big(\tfrac{\pi}{3}+\tfrac12\times\tfrac{\sqrt3}{2}\big)-\big(0+0\big)\\&=\tfrac{\pi}{3}+\tfrac{\sqrt3}{4}\end{aligned}\] Your turn.

a Using \(\cos^2x=\tfrac12+\tfrac12\cos2x\),

\[\begin{aligned}\int_{0}^{\frac{\pi}{2}}\cos^2x\,dx&=\int_{0}^{\frac{\pi}{2}}\big(\tfrac12+\tfrac12\cos2x\big)\,dx\\&=\Big[\tfrac12x+\tfrac14\sin2x\Big]_{0}^{\frac{\pi}{2}}\\&=\big(\tfrac{\pi}{4}+\tfrac14\sin\pi\big)-\big(0+\tfrac14\sin0\big)\\&=\big(\tfrac{\pi}{4}+0\big)-\big(0+0\big)\\&=\tfrac{\pi}{4}\end{aligned}\]

b Using \(\sin^2\tfrac13x=\tfrac12-\tfrac12\cos\tfrac23x\),

\[\begin{aligned}\int_{0}^{\pi}\sin^2\tfrac13x\,dx&=\int_{0}^{\pi}\big(\tfrac12-\tfrac12\cos\tfrac23x\big)\,dx\\&=\Big[\tfrac12x-\tfrac34\sin\tfrac23x\Big]_{0}^{\pi}\\&=\big(\tfrac{\pi}{2}-\tfrac34\sin\tfrac{2\pi}{3}\big)-\big(0-\tfrac34\sin0\big)\\&=\big(\tfrac{\pi}{2}-\tfrac34\times\tfrac{\sqrt3}{2}\big)-\big(0-0\big)\\&=\tfrac{\pi}{2}-\tfrac{3\sqrt3}{8}\end{aligned}\]

The primitive of \(-\tfrac12\cos\tfrac23x\) is \(-\tfrac12\times\tfrac32\sin\tfrac23x=-\tfrac34\sin\tfrac23x\).

Tutor demo.

a Using \(2\sin A\cos B=\sin(A+B)+\sin(A-B)\) with \(A=4x\) and \(B=x\), \(\ \sin4x\cos x=\tfrac12(\sin5x+\sin3x)\). So

\[\begin{aligned}\int\sin4x\cos x\,dx&=\tfrac12\int(\sin5x+\sin3x)\,dx\\&=\tfrac12\big(-\tfrac15\cos5x-\tfrac13\cos3x\big)+C\\&=-\tfrac{1}{10}\cos5x-\tfrac16\cos3x+C\end{aligned}\]

b Using \(-2\sin A\sin B=\cos(A+B)-\cos(A-B)\) with \(A=3x\) and \(B=x\), \(\ 2\sin3x\sin x=-(\cos4x-\cos2x)=\cos2x-\cos4x\). So

\[\begin{aligned}\int_{0}^{\frac{\pi}{6}}2\sin3x\sin x\,dx&=\int_{0}^{\frac{\pi}{6}}(\cos2x-\cos4x)\,dx\\&=\Big[\tfrac12\sin2x-\tfrac14\sin4x\Big]_{0}^{\frac{\pi}{6}}\\&=\big(\tfrac12\sin\tfrac{\pi}{3}-\tfrac14\sin\tfrac{2\pi}{3}\big)-\big(\tfrac12\sin0-\tfrac14\sin0\big)\\&=\big(\tfrac12\times\tfrac{\sqrt3}{2}-\tfrac14\times\tfrac{\sqrt3}{2}\big)-0\\&=\tfrac{\sqrt3}{4}-\tfrac{\sqrt3}{8}\\&=\tfrac{\sqrt3}{8}\end{aligned}\] Your turn.

a Using \(2\cos A\sin B=\sin(A+B)-\sin(A-B)\) with \(A=4x\) and \(B=2x\), \(\ \cos4x\sin2x=\tfrac12(\sin6x-\sin2x)\). So

\[\begin{aligned}\int\cos4x\sin2x\,dx&=\tfrac12\int(\sin6x-\sin2x)\,dx\\&=\tfrac12\big(-\tfrac16\cos6x+\tfrac12\cos2x\big)+C\\&=-\tfrac{1}{12}\cos6x+\tfrac14\cos2x+C\end{aligned}\]

b Using \(2\cos A\cos B=\cos(A+B)+\cos(A-B)\) with \(A=3x\) and \(B=x\), \(\ 2\cos3x\cos x=\cos4x+\cos2x\). So

\[\begin{aligned}\int_{0}^{\frac{\pi}{4}}2\cos3x\cos x\,dx&=\int_{0}^{\frac{\pi}{4}}(\cos4x+\cos2x)\,dx\\&=\Big[\tfrac14\sin4x+\tfrac12\sin2x\Big]_{0}^{\frac{\pi}{4}}\\&=\big(\tfrac14\sin\pi+\tfrac12\sin\tfrac{\pi}{2}\big)-\big(\tfrac14\sin0+\tfrac12\sin0\big)\\&=\big(0+\tfrac12\big)-0\\&=\tfrac12\end{aligned}\]

Tutor demo.

a

\[\begin{aligned}\int\sin x\cos^6x\,dx&=-\int(-\sin x)\cos^6x\,dx\\&=-\tfrac17\cos^7x+C\end{aligned}\]

Let \(u=\cos x\).
Then \(\frac{du}{dx}=-\sin x\),
and \(\displaystyle\int u^6\,\frac{du}{dx}\,dx=\tfrac17u^7\).

b

\[\int\sec^2x\tan^nx\,dx=\frac{\tan^{n+1}x}{n+1}+C\]

Let \(u=\tan x\).
Then \(\frac{du}{dx}=\sec^2x\),
and \(\displaystyle\int u^n\,\frac{du}{dx}\,dx=\frac{u^{n+1}}{n+1}\).

Your turn.

a

\[\int\cos x\sin^5x\,dx=\tfrac16\sin^6x+C\]

Let \(u=\sin x\).
Then \(\frac{du}{dx}=\cos x\),
and \(\displaystyle\int u^5\,\frac{du}{dx}\,dx=\tfrac16u^6\).

b

\[\begin{aligned}\int\sin x\cos^nx\,dx&=-\int(-\sin x)\cos^nx\,dx\\&=-\frac{\cos^{n+1}x}{n+1}+C\end{aligned}\]

Let \(u=\cos x\).
Then \(\frac{du}{dx}=-\sin x\),
and \(\displaystyle\int u^n\,\frac{du}{dx}\,dx=\frac{u^{n+1}}{n+1}\).

A square is never negative, so \(y=\cos^2(3x)\ge0\) and the area is the integral. Using \(\cos^2\theta=\tfrac12+\tfrac12\cos2\theta\) with \(\theta=3x\),

\[\begin{aligned}A&=\int_{\frac{\pi}{6}}^{\frac{\pi}{3}}\cos^2(3x)\,dx\\&=\int_{\frac{\pi}{6}}^{\frac{\pi}{3}}\big(\tfrac12+\tfrac12\cos6x\big)\,dx\\&=\Big[\tfrac12x+\tfrac{1}{12}\sin6x\Big]_{\frac{\pi}{6}}^{\frac{\pi}{3}}\\&=\big(\tfrac{\pi}{6}+\tfrac{1}{12}\sin2\pi\big)-\big(\tfrac{\pi}{12}+\tfrac{1}{12}\sin\pi\big)\\&=\big(\tfrac{\pi}{6}+0\big)-\big(\tfrac{\pi}{12}+0\big)\\&=\tfrac{\pi}{12}\end{aligned}\]

The area is \(\tfrac{\pi}{12}\) square units.
