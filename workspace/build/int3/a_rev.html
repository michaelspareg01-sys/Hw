Each inverse trigonometric value must lie in the range of the function: \(-\tfrac{\pi}{2}\le\sin^{-1}x\le\tfrac{\pi}{2}\), \(\ 0\le\cos^{-1}x\le\pi\), \(\ -\tfrac{\pi}{2}\lt\tan^{-1}x\lt\tfrac{\pi}{2}\).

Exercise 17B Q5
a \(\sin\tfrac{4\pi}{3}=-\tfrac{\sqrt3}{2}\) (third quadrant, related angle \(\tfrac{\pi}{3}\)), so \(\sin^{-1}\big(\sin\tfrac{4\pi}{3}\big)=\sin^{-1}\Big(-\tfrac{\sqrt3}{2}\Big)=-\tfrac{\pi}{3}\). The answer is not \(\tfrac{4\pi}{3}\), which is outside the range of \(\sin^{-1}\).
b \(\cos\big(-\tfrac{\pi}{4}\big)=\tfrac{1}{\sqrt2}\), so \(\cos^{-1}\Big(\cos\big(-\tfrac{\pi}{4}\big)\Big)=\cos^{-1}\tfrac{1}{\sqrt2}=\tfrac{\pi}{4}\).
c \(\tan\tfrac{5\pi}{6}=-\tfrac{1}{\sqrt3}\) (second quadrant, related angle \(\tfrac{\pi}{6}\)), so \(\tan^{-1}\big(\tan\tfrac{5\pi}{6}\big)=\tan^{-1}\Big(-\tfrac{1}{\sqrt3}\Big)=-\tfrac{\pi}{6}\).
d \(\cos\tfrac{5\pi}{4}=-\tfrac{1}{\sqrt2}\) (third quadrant, related angle \(\tfrac{\pi}{4}\)), so \(\cos^{-1}\big(\cos\tfrac{5\pi}{4}\big)=\cos^{-1}\Big(-\tfrac{1}{\sqrt2}\Big)=\tfrac{3\pi}{4}\).
e \(2\sin\big(-\tfrac{\pi}{6}\big)=2\times\big(-\tfrac12\big)=-1\), so \(\arcsin\Big(2\sin\big(-\tfrac{\pi}{6}\big)\Big)=\arcsin(-1)=-\tfrac{\pi}{2}\).
f \(3\tan\tfrac{7\pi}{6}=3\times\tfrac{1}{\sqrt3}=\sqrt3\) (third quadrant, where \(\tan\) is positive), so \(\arctan\big(3\tan\tfrac{7\pi}{6}\big)=\arctan\sqrt3=\tfrac{\pi}{3}\).

Exercise 17C Q2
a \(y=\sin^{-1}(x-1)\) is \(y=\sin^{-1}x\) shifted right 1 unit. It needs \(-1\le x-1\le1\), so the domain is \(0\le x\le2\). The range is \(-\tfrac{\pi}{2}\le y\le\tfrac{\pi}{2}\). Key points: \(\big(0,-\tfrac{\pi}{2}\big)\), \((1,0)\), \(\big(2,\tfrac{\pi}{2}\big)\). The function is neither even nor odd, because its domain is not symmetric about the \(y\)-axis.
b \(y=\cos^{-1}(x+1)\) is \(y=\cos^{-1}x\) shifted left 1 unit. It needs \(-1\le x+1\le1\), so the domain is \(-2\le x\le0\). The range is \(0\le y\le\pi\). Key points: \((-2,\pi)\), \(\big(-1,\tfrac{\pi}{2}\big)\), \((0,0)\). The function is neither even nor odd.
c \(y=\tfrac{\pi}{2}+\tan^{-1}x\) is \(y=\tan^{-1}x\) shifted up \(\tfrac{\pi}{2}\) units. The domain is all real \(x\), and the range is \(0\lt y\lt\pi\). The \(y\)-intercept is \(\big(0,\tfrac{\pi}{2}\big)\). As \(x\to\infty\), \(y\to\pi\), and as \(x\to-\infty\), \(y\to0\), so the asymptotes are \(y=0\) and \(y=\pi\). The function is neither even nor odd: replacing \(x\) by \(-x\) gives \(\tfrac{\pi}{2}-\tan^{-1}x\), which is neither \(y\) nor \(-y\).

a Let \(\alpha=\cos^{-1}\tfrac13\). Then \(\cos\alpha=\tfrac13\), where \(0\le\alpha\le\pi\).
\(\cos\big(2\cos^{-1}\tfrac13\big)=\cos2\alpha=2\cos^2\alpha-1=2\times\tfrac19-1=-\tfrac79\)
b Let \(\alpha=\cos^{-1}\tfrac67\). Then \(\cos\alpha=\tfrac67\), where \(0\le\alpha\le\pi\), so \(\alpha\) is in the first quadrant.
The third side of the triangle is \(\sqrt{7^2-6^2}=\sqrt{13}\), so \(\sin\alpha=\tfrac{\sqrt{13}}{7}\).
\(\sin\big(2\cos^{-1}\tfrac67\big)=\sin2\alpha=2\sin\alpha\cos\alpha=2\times\tfrac{\sqrt{13}}{7}\times\tfrac67=\tfrac{12\sqrt{13}}{49}\)
c Let \(\alpha=\tan^{-1}(-2)\). Then \(\tan\alpha=-2\), where \(-\tfrac{\pi}{2}\lt\alpha\lt\tfrac{\pi}{2}\).
\(\tan\big(2\tan^{-1}(-2)\big)=\tan2\alpha=\dfrac{2\tan\alpha}{1-\tan^2\alpha}=\dfrac{2\times(-2)}{1-(-2)^2}=\dfrac{-4}{-3}=\dfrac43\)
