Lesson 12A

Inverse trigonometric functions: differentiating

Derive and use the derivatives of \(\sin^{-1}x\), \(\cos^{-1}x\) and \(\tan^{-1}x\), with linear and chain-rule extensions, and apply them to tangents, constant functions and curve sketching.
{{sec:teal:key:Concept 1:the three standard derivatives}}
Deriving the derivatives

Change to the inverse function and use the known derivative of sine, cosine or tangent. Keep track of the restriction on \(y\) so that the correct square root (positive or negative) is chosen.

A Let \(y=\sin^{-1}x\). Then \(x=\sin y\), where \(-\tfrac{\pi}{2}\le y\le\tfrac{\pi}{2}\).

\[\dfrac{dx}{dy}=\cos y\]

Because \(y\) is in quadrant 1 or 4, \(\cos y\ge0\), so \(\cos y=+\sqrt{1-\sin^2y}=\sqrt{1-x^2}\). Hence

\[\dfrac{d}{dx}\sin^{-1}x=\dfrac{1}{\sqrt{1-x^2}}.\]

B Let \(y=\cos^{-1}x\). Then \(x=\cos y\), where \(0\le y\le\pi\).

\[\dfrac{dx}{dy}=-\sin y\]

Because \(y\) is in quadrant 1 or 2, \(\sin y\ge0\), so \(\sin y=+\sqrt{1-\cos^2y}=\sqrt{1-x^2}\). Hence

\[\dfrac{d}{dx}\cos^{-1}x=-\dfrac{1}{\sqrt{1-x^2}}.\]

C Let \(y=\tan^{-1}x\), so \(x=\tan y\), where \(-\tfrac{\pi}{2} \[\dfrac{d}{dx}\tan^{-1}x=\dfrac{1}{1+x^2}.\]

Standard forms, with linear extensions
\[\dfrac{d}{dx}\sin^{-1}x=\dfrac{1}{\sqrt{1-x^2}}\qquad \dfrac{d}{dx}\cos^{-1}x=-\dfrac{1}{\sqrt{1-x^2}}\qquad \dfrac{d}{dx}\tan^{-1}x=\dfrac{1}{1+x^2}\] \[\dfrac{d}{dx}\sin^{-1}(ax+b)=\dfrac{a}{\sqrt{1-(ax+b)^2}}\qquad \dfrac{d}{dx}\cos^{-1}(ax+b)=-\dfrac{a}{\sqrt{1-(ax+b)^2}}\qquad \dfrac{d}{dx}\tan^{-1}(ax+b)=\dfrac{a}{1+(ax+b)^2}\]

Solution

a Product rule with \(u=x\), \(v=\tan^{-1}x\), so \(u'=1\), \(v'=\dfrac{1}{1+x^2}\):

\[\begin{aligned} y'&=vu'+uv'\\ &=\tan^{-1}x\times1+x\times\dfrac{1}{1+x^2}\\ &=\tan^{-1}x+\dfrac{x}{1+x^2}\end{aligned}\]

b Chain rule with \(u=ax+b\), \(y=\sin^{-1}u\):

\[\begin{aligned} \dfrac{dy}{dx}&=\dfrac{dy}{du}\times\dfrac{du}{dx}\\ &=\dfrac{1}{\sqrt{1-(ax+b)^2}}\times a\\ &=\dfrac{a}{\sqrt{1-(ax+b)^2}}\end{aligned}\]
{{sec:teal:key:Concept 2:gradients and tangents}}
Using the derivative

Set \(y'\) equal to the required gradient and solve, or substitute \(x\) into \(y'\) to find the gradient of a tangent. Always check that the \(x\)-values found lie in the domain, and that the \(y\)-values are in the range of the inverse function.

Proving identities with calculus

If \(f'(x)=0\) for all \(x\) in an interval, then \(f(x)\) is constant on that interval. To find the constant, substitute any convenient value of \(x\) in the interval.

If the domain is split into separate intervals, the constant may be different on each interval.

a Differentiate \(\sin^{-1}x+\cos^{-1}x\).   b Hence prove the identity \(\sin^{-1}x+\cos^{-1}x=\tfrac{\pi}{2}\).
Solution
\[\textbf{a}\quad \dfrac{d}{dx}\left(\sin^{-1}x+\cos^{-1}x\right)=\dfrac{1}{\sqrt{1-x^2}}+\dfrac{-1}{\sqrt{1-x^2}}=0\]

{{sec:teal:key:Concept 4:curve sketching using calculus}}
Sketching with the derivative

The usual methods of curve sketching (domain, symmetry, intercepts, a table of values, the sign of \(y'\)) extend to curves involving inverse trigonometric functions. Watch for square roots such as \(\sqrt{\sin^2x}=|\sin x|\), which give different formulae in different quadrants.

Worked example 4Keep for homework
Use calculus to sketch \(y=\cos^{-1}(\cos x)\).
Solution

The function is periodic with the same period \(2\pi\) as \(\cos x\). A table of test values gives key points:

\(x\)0\(\tfrac{\pi}{2}\)\(\pi\)\(\tfrac{3\pi}{2}\)\(2\pi\)\(\tfrac{5\pi}{2}\)\(3\pi\)
\(y\)0\(\tfrac{\pi}{2}\)\(\pi\)\(\tfrac{\pi}{2}\)0\(\tfrac{\pi}{2}\)\(\pi\)

Differentiating with the chain rule (\(u=\cos x\), \(y=\cos^{-1}u\)):

\[\dfrac{dy}{dx}=-\dfrac{1}{\sqrt{1-\cos^2x}}\times(-\sin x)=\dfrac{\sin x}{\sqrt{\sin^2x}}\]

When \(\sin x>0\), \(\sqrt{\sin^2x}=\sin x\), so \(\dfrac{dy}{dx}=1\). When \(\sin x<0\), \(\sqrt{\sin^2x}=-\sin x\), so \(\dfrac{dy}{dx}=-1\). So \(y'=1\) for \(x\) in quadrants 1 and 2, and \(y'=-1\) in quadrants 3 and 4: the graph is a series of line segments of gradient \(\pm1\).

{{sec:teal:key:Concept 5:chain-rule extensions}}
Chain-rule extensions to the standard forms
\[\dfrac{d}{dx}\sin^{-1}f(x)=\dfrac{f'(x)}{\sqrt{1-\big(f(x)\big)^2}}\qquad \dfrac{d}{dx}\cos^{-1}f(x)=-\dfrac{f'(x)}{\sqrt{1-\big(f(x)\big)^2}}\qquad \dfrac{d}{dx}\tan^{-1}f(x)=\dfrac{f'(x)}{1+\big(f(x)\big)^2}\]

Equivalently, with \(u=f(x)\): \(\dfrac{u'}{\sqrt{1-u^2}}\), \(-\dfrac{u'}{\sqrt{1-u^2}}\) and \(\dfrac{u'}{1+u^2}\).

Use the chain-rule extension formulae to differentiate: a \(\tan^{-1}e^{-5x}\)    b \(\cos^{-1}(3x^2)\)
Solution

a Here \(f(x)=e^{-5x}\) and \(f'(x)=-5e^{-5x}\), so

\[\dfrac{d}{dx}\left(\tan^{-1}e^{-5x}\right)=\dfrac{f'(x)}{1+\big(f(x)\big)^2}=\dfrac{-5e^{-5x}}{1+e^{-10x}}.\]

b Here \(f(x)=3x^2\) and \(f'(x)=6x\), so

\[\dfrac{d}{dx}\left(\cos^{-1}3x^2\right)=-\dfrac{f'(x)}{\sqrt{1-\big(f(x)\big)^2}}=-\dfrac{6x}{\sqrt{1-9x^4}}.\]
