Lesson 12D

Integration by substitution

Rewrite the reverse chain rule in the notation of substitution, "let \(u=\) some function of \(x\)", and change the limits of a definite integral so there is no need to return to \(x\).
{{sec:teal:key:Concept 1:from the reverse chain rule to substitution}}
The new notation

The reverse chain rule does not cover every situation where the chain rule can be used in integration. Integration by substitution is a more general method. Its first stage uses substitutions of the form \(\text{Let }u=\text{some function of }x\).

The key to the notation is that the derivative \(\dfrac{du}{dx}\) is treated as a fraction: the \(du\) and the \(dx\) are split apart, so that \(\dfrac{du}{dx}=-2x\) is written instead as \(du=-2x\,dx\). The new variable \(u\) then appears in the main line of working, not only in a side column.

The method
  1. Write down \(u\) and find \(du\) in terms of \(dx\).
  2. Replace every \(x\) expression in the integrand (and the \(dx\)) by \(u\) expressions (and \(du\)).
  3. Integrate with respect to \(u\).
  4. For an indefinite integral, substitute back to \(x\).
Worked example 1The same integral, two notations
Find \(\displaystyle\int x(1-x^2)^4\,dx\): a by the reverse chain rule, b using the substitution \(u=1-x^2\).
Solution

a Reverse chain rule (\(u=1-x^2\), \(\tfrac{du}{dx}=-2x\) in the side working):

\[\begin{aligned}\int x(1-x^2)^4\,dx&=-\tfrac12\int(-2x)(1-x^2)^4\,dx\\&=-\tfrac12\times\tfrac15(1-x^2)^5+C\\&=-\tfrac{1}{10}(1-x^2)^5+C\end{aligned}\]

b Let \(u=1-x^2\). Then \(du=-2x\,dx\), and \(x\,dx=-\tfrac12\,du\).

\[\begin{aligned}\int x(1-x^2)^4\,dx&=\int u^4\left(-\tfrac12\right)du\\&=-\tfrac12\times\tfrac15u^5+C\\&=-\tfrac{1}{10}(1-x^2)^5+C\end{aligned}\]

When the reverse chain rule is clumsy

Some integrals that can be done this way could only be done by the reverse chain rule in a rather clumsy manner. If, after replacing \(dx\), some \(x\) is left over, use the equation for \(u\) to write that \(x\) in terms of \(u\) as well (for example \(u=1-x\) gives \(x=1-u\)).

Worked example 2Keep for homework
Find: a \(\displaystyle\int\sin x\sqrt{1-\cos x}\,dx\), using \(u=1-\cos x\)    b \(\displaystyle\int x\sqrt{1-x}\,dx\), using \(u=1-x\)
Solution

a Let \(u=1-\cos x\). Then \(du=\sin x\,dx\).

\[\begin{aligned}\int\sin x\sqrt{1-\cos x}\,dx&=\int u^{\frac12}\,du\\&=\tfrac23u^{\frac32}+C\\&=\tfrac23(1-\cos x)^{\frac32}+C\end{aligned}\]

b Let \(u=1-x\). Then \(du=-dx\), and \(x=1-u\).

\[\begin{aligned}\int x\sqrt{1-x}\,dx&=\int(1-u)\sqrt{u}\,(-du)\\&=\int\left(u^{\frac32}-u^{\frac12}\right)du\\&=\tfrac25u^{\frac52}-\tfrac23u^{\frac32}+C\\&=\tfrac25(1-x)^{\frac52}-\tfrac23(1-x)^{\frac32}+C\end{aligned}\]
{{sec:teal:key:Concept 3:substituting the limits of integration}}
Definite integrals

A great advantage of the new method is that the limits of integration can be changed from values of \(x\) to values of \(u\). There is then no need ever to go back to \(x\).

Write the new limits in the side working: "When \(x=\dots\), \(u=\dots\)". The lower limit stays at the bottom of the integral even if it is the larger number.

Worked example 3Keep for homework
Find: a \(\displaystyle\int_0^1 x\sqrt{1-x}\,dx\), using \(u=1-x\)    b \(\displaystyle\int_0^{\pi}\sin x\cos^6x\,dx\), using \(u=\cos x\)
Solution

a Let \(u=1-x\). Then \(du=-dx\) and \(x=1-u\). When \(x=0\), \(u=1\); when \(x=1\), \(u=0\).

\[\begin{aligned}\int_0^1 x\sqrt{1-x}\,dx&=-\int_1^0(1-u)\sqrt{u}\,du\\&=-\int_1^0\left(u^{\frac12}-u^{\frac32}\right)du\\&=-\Big[\tfrac23u^{\frac32}-\tfrac25u^{\frac52}\Big]_1^0\\&=-0+\left(\tfrac23-\tfrac25\right)=\tfrac{4}{15}\end{aligned}\]

b Let \(u=\cos x\). Then \(du=-\sin x\,dx\). When \(x=0\), \(u=1\); when \(x=\pi\), \(u=-1\).

\[\begin{aligned}\int_0^{\pi}\sin x\cos^6x\,dx&=-\int_1^{-1}u^6\,du\\&=-\tfrac17\Big[u^7\Big]_1^{-1}\\&=-\tfrac17\times(-1)+\tfrac17\times1\\&=\tfrac27\end{aligned}\]
