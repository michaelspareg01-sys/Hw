Lesson 12E

Further integration by substitution

Reverse the procedure of Lesson 12D: replace \(x\) by a function of \(u\) (or of \(\theta\)), including trigonometric substitutions such as \(x=a\sin\theta\).
{{sec:teal:key:Concept 1:substituting x by a function of u}}
"Let x = some function of u"

The second stage of integration by substitution replaces \(x\) by a function of \(u\). Then

  • find \(dx\) in terms of \(du\) by differentiating \(x\) with respect to \(u\);
  • write every part of the integrand in terms of \(u\) (for example, if \(x=1-u^2\) then \(\sqrt{1-x}=u\));
  • change the limits to values of \(u\), or substitute back at the end for an indefinite integral.

Common choices: \(x=u^2\pm c\) to remove a square root \(\sqrt{x\pm c}\); \(x=u\pm c\) to simplify a denominator.

Worked example 1Keep for homework
Find \(\displaystyle\int_0^1 x\sqrt{1-x}\,dx\), using the substitution \(x=1-u^2\).
Solution

Let \(x=1-u^2\). Then \(dx=-2u\,du\), and \(\sqrt{1-x}=u\). When \(x=0\), \(u=1\); when \(x=1\), \(u=0\).

\[\begin{aligned}\int_0^1x\sqrt{1-x}\,dx&=\int_1^0(1-u^2)\,u\,(-2u)\,du\\&=-2\int_1^0\left(u^2-u^4\right)du\\&=-2\Big[\tfrac13u^3-\tfrac15u^5\Big]_1^0\\&=-0+2\left(\tfrac13-\tfrac15\right)=\tfrac{4}{15}\end{aligned}\]

This is the integral of Worked Example 3a in Lesson 12D, done a quite different way.

{{sec:teal:key:Concept 2:trigonometric substitutions}}
x = a sin θ, x = a tan θ, ...

An expression \(\sqrt{a^2-x^2}\) suggests \(x=a\sin\theta\), because then \(\sqrt{a^2-x^2}=\sqrt{a^2\cos^2\theta}=a\cos\theta\). Similarly \(a^2+x^2\) suggests \(x=a\tan\theta\), because \(a^2+a^2\tan^2\theta=a^2\sec^2\theta\).

Rule of thumb. Work with positive square roots, and keep \(\theta\) in the same quadrants as in the definitions of the inverse trigonometric functions (for \(x=a\sin\theta\), use \(-\tfrac{\pi}{2}\le\theta\le\tfrac{\pi}{2}\), where \(\cos\theta\ge0\)).

Strictly, given a value of \(x\) there are infinitely many possible \(\theta\); choosing \(\theta\) in this restricted interval removes the ambiguity. A full account is not required in this course.

Worked example 2Keep for homework
Find \(\displaystyle\int_{3\sqrt2}^{6}\sqrt{36-x^2}\,dx\): a using the substitution \(x=6\sin u\), b using the formula for the area of a segment.
Solution

a Let \(x=6\sin u\). Then \(dx=6\cos u\,du\) and \(\sqrt{36-x^2}=6\cos u\). When \(x=3\sqrt2\), \(u=\tfrac{\pi}{4}\); when \(x=6\), \(u=\tfrac{\pi}{2}\).

\[\begin{aligned}\int_{3\sqrt2}^{6}\sqrt{36-x^2}\,dx&=\int_{\frac{\pi}{4}}^{\frac{\pi}{2}}6\cos u\times6\cos u\,du\\&=\int_{\frac{\pi}{4}}^{\frac{\pi}{2}}36\left(\tfrac12+\tfrac12\cos 2u\right)du\\&=\Big[18u+9\sin 2u\Big]_{\frac{\pi}{4}}^{\frac{\pi}{2}}\\&=(9\pi+0)-\left(\tfrac{9\pi}{2}+9\right)\\&=\tfrac92(\pi-2)\end{aligned}\]

b The integral is the area under the semicircle \(y=\sqrt{36-x^2}\) from \(x=3\sqrt2\) to \(x=6\). This is half the segment of the circle of radius 6 cut off by the chord \(x=3\sqrt2\), which subtends an angle of \(90^\circ\) at the centre. Using segment area \(\tfrac12r^2(\theta-\sin\theta)\):

\[\int_{3\sqrt2}^{6}\sqrt{36-x^2}\,dx=\tfrac12\times\tfrac12\times6^2\left(\tfrac{\pi}{2}-\sin\tfrac{\pi}{2}\right)=9\left(\tfrac{\pi}{2}-1\right)\]
Summary of Lessons 12D and 12E
  • The reverse chain rule straightforwardly reverses the steps of differentiation by the chain rule.
  • A reverse-chain-rule formula can be developed for each standard form.
  • Substitution can be done by "Let \(u\) be a function of \(x\)".
  • Substitution can be done by "Let \(x\) be a function of \(u\)".
  • When substituting into a definite integral, the limits of integration can be substituted as well, so that there is no need ever to return from \(u\) to \(x\).
