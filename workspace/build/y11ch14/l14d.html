Lesson 14D

Ordered selections with identical elements

So far, our ordered sets have not permitted any element to be repeated. This lesson deals with permutations of all the letters of a word containing several copies of the one letter. Swapping identical letters does not change a word, so we must allow for overcounting.
{{sec:teal:key:Concept 1:counting with identical elements}}
Counting with identical elements

Finding the number of different words formed using all the letters of the word ‘PRESSES’ is complicated by the fact that there are three Ss and two Es. If the seven letters were all different, we would conclude that

\[\text{number of ways}=7!\]

But we have overcounted by a factor of \(2!=2\), because the Es can be interchanged without changing the word. We have also overcounted by a factor of \(3!=6\), because the three Ss can be permuted amongst themselves in \(3!\) ways without changing the word. Taking account of both overcountings,

\[\text{number of ways}=\dfrac{7!}{2!\times3!}=420.\]

This method is easily generalised. In the language of ‘words’:

Box 10  Counting with identical elements

Suppose that a word of \(n\) letters has \(r_1\) alike of one type, \(r_2\) alike of another type, …, \(r_k\) alike of a final type. Then the number of distinct words that can be formed by rearranging the letters is

\[\text{number of words}=\dfrac{n!}{r_1!\times r_2!\times\cdots\times r_k!}.\]

If \(r_i=1\), that is, there is only one letter of the \(i\)th type, then \(r_i!=1\), so it doesn’t matter whether we include it in the formula or not.

{{sec:teal:key:Concept 2:words containing only two different letters}}
Words containing only two different letters

The theory about counting with identical letters assumes particular importance when there are only two types of letters, as in part a of Worked example 12. The answer to part a was \(\dfrac{8!}{3!\times5!}\). This formula is true in general:

Box 11  Permutations of words containing only two different letters

Suppose that an \(n\)-letter word consists of \(r\) Ys and \(n-r\) Ns. Then the number of possible distinct words is

\[\text{number of words}=\dfrac{n!}{r!\times(n-r)!}.\]
An application: paths on a grid

A path from \(A\) to \(B\) along the grid lines, moving only right or down, is a list of single steps. On the 3 by 2 grid of unit squares shown, every path has 3 steps right (R) and 2 steps down (D), so each path is a five-letter word with three Rs and two Ds. The path drawn is RDRRD. Each such word gives exactly one path, so by Box 11

\[\text{number of paths}=\dfrac{5!}{3!\times2!}=10.\]

Using cases

As mentioned in Lesson 14C, many counting problems are too complicated to be analysed completely by a single box diagram. In such situations, the use of cases is unavoidable. Attention should be given, however, to minimising the number of different cases that need to be considered.

Worked example 14Keep for homework
How many six-letter words can be formed by using the letters of the word ‘PRESSES’?
Solution

We omit in turn each of the four letters ‘P’, ‘R’, ‘E’ and ‘S’. This leaves six letters which we must then arrange in order.

1 If an S is omitted, there are then 2 Es and 2 Ss, so

\[\text{number of words}=\dfrac{6!}{2!\times2!}=180.\]

2 If an E is omitted, there are then 3 Ss, so

\[\text{number of words}=\dfrac{6!}{3!}=120.\]

3 If P or R is omitted (2 cases), there are then 2 Es and 3 Ss, so

\[\begin{aligned}\text{number of words}&=\dfrac{6!}{3!\times2!}\times2\\ &=120.\end{aligned}\]

(doubling for the two cases)

\[\text{Hence the total number of words is }180+120+120=420.\]
